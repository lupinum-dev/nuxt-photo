---
title: Use Nuxt Photo with Vue
description: Use the components in a plain Vue 3 app with Vite - install @lupinum/vue-photo, import components and the stylesheet, and choose image delivery without Nuxt Image.
---

Plain Vue applications use `@lupinum/vue-photo`. They do not install or register
the Nuxt module.

::warning
These docs describe the 1.0 beta. Install the `next` release while npm `latest`
remains on 0.2.
::

## Install

::pm-install{name="@lupinum/vue-photo@next"}
::

## Render the first album

Import components and types from the Vue package root. Import the complete
stylesheet once from the application entry or root component.

```vue [src/App.vue]
<script setup lang="ts">
import { PhotoAlbum, type PhotoItem } from '@lupinum/vue-photo'
import '@lupinum/vue-photo/styles.css'

const photos: PhotoItem[] = [
  {
    id: 'dunes',
    src: '/photos/dunes.jpg',
    width: 1280,
    height: 800,
    alt: 'Dunes at sunset',
  },
  {
    id: 'coast',
    src: '/photos/coast.jpg',
    width: 960,
    height: 1200,
    alt: 'Rocky coast from above',
  },
]
</script>

<template>
  <PhotoAlbum :photos="photos" :layout="{ type: 'rows', targetRowHeight: 240 }" />
</template>
```

No plugin registration is needed. Import every component, composable, type,
and helper from `@lupinum/vue-photo`. The rest of these docs uses Nuxt
auto-imports; in Vue, import the same names from the package root.

Nuxt Image works only with the Nuxt module. In a plain Vue app, use the native
`src`, `thumbSrc`, and `srcset` fields of each photo, or provide your own
[image adapter](/docs/guides/integrate-a-custom-image-service).

---
title: Use Nuxt Photo with Vue
description: Use the components in a plain Vue 3 app with Vite - install @lupinum/vue-photo, import components and the stylesheet, set labels, lightbox and image provider once with createPhoto, and deliver images without Nuxt Image.
---

Plain Vue applications use `@lupinum/vue-photo`. They do not install or register
the Nuxt module.

## Install

::pm-install{name="@lupinum/vue-photo"}
::

Then exclude the package from Vite's dependency pre-bundling:

```ts [vite.config.ts]
import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [vue()],
  optimizeDeps: { exclude: ['@lupinum/vue-photo'] },
})
```

The package ships Vue single-file components. Without this line, the Vite dev
server loads the package twice, and the options you set with `createPhoto` do
not reach the components. Production builds are not affected.

## Render the first album

Import components and types from the Vue package root. Import the complete
stylesheet once from the application entry or root component.

```vue [src/App.vue]
<script setup lang="ts">
import { PhotoAlbum, type PhotoItem } from '@lupinum/vue-photo'
import '@lupinum/vue-photo/styles.css'

const photos: PhotoItem[] = [
  {
    id: 'dunes',
    src: '/photos/dunes.jpg',
    width: 1280,
    height: 800,
    alt: 'Dunes at sunset',
  },
  {
    id: 'coast',
    src: '/photos/coast.jpg',
    width: 960,
    height: 1200,
    alt: 'Rocky coast from above',
  },
]
</script>

<template>
  <PhotoAlbum :photos="photos" :layout="{ type: 'rows', targetRowHeight: 240 }" />
</template>
```

The components work without setup. Import every component, composable,
type, and helper from `@lupinum/vue-photo`, and the lightbox primitives from
`@lupinum/vue-photo/primitives`. The rest of these docs uses Nuxt auto-imports;
in Vue, import the same names from these entries.

`styles.css` holds every stylesheet. To load less, import single files such as
`@lupinum/vue-photo/styles/album.css`; [CSS](/docs/reference/css) lists them.

## Set options for the whole app

`createPhoto` sets labels, lightbox options, validation and the image provider
once:

```ts [src/main.ts]
import { createApp } from 'vue'
import { createPhoto } from '@lupinum/vue-photo'
import App from './App.vue'

createApp(App)
  .use(
    createPhoto({
      labels: 'de',
      lightbox: { tools: ['download', 'fullscreen'] },
    }),
  )
  .mount('#app')
```

To resize images on your CDN, add a `provider` here;
[Integrate a custom image service](/docs/guides/integrate-a-custom-image-service)
shows the file.

A component's own props win over these values. A wrong option throws a
`TypeError` when the app starts. Without `labels`, the language comes from
`<html lang>`, with English as the fallback. When you render on the server,
set `labels` explicitly, so server and browser use the same language.

## Deliver images

Nuxt Image works only with the Nuxt module. Without a provider, each image
uses the photo's own fields: `thumbSrc` or `src` for thumbnails, `src` for
slides, and `srcset` when you set it. `PhotoAlbum` writes `sizes` from its
layout. For resized images from your CDN, write a
[provider](/docs/guides/integrate-a-custom-image-service): Nuxt Photo then
builds `srcset` from 128 to 2560 px, never wider than the photo.

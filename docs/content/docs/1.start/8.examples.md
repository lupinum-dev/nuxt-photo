Each example is a complete component. It runs on this page with the real
package, and the code under it is the same file. Every example takes a
`photos` prop; pass your own `PhotoItem` array.

## Portfolio grid

Columns with a caption under each photo. The lightbox crossfades between
photos, and the column count follows the container width.

::example{name="portfolio-grid"}
::

## Photos inside an article

One `PhotoGroup` owns the order, so the lightbox moves through the lead photo
and the album below it as one set.

A lightbox built from the lower-level components and styled only with Tailwind

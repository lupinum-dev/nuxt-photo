Nuxt Photo is built to be used through a coding agent. The agent needs the
rules that break a gallery when they are wrong, such as real image sizes and
stable IDs. These sources give it those rules without guessing.

## Install the skill

The skill teaches an agent the Nuxt Photo workflow, its rules, and the most
common tasks. Install it in your project:

```bash [Terminal]
npx skills add lupinum-dev/nuxt-photo
```

The command asks which agents to install for, such as Claude Code, Codex, or
Cursor. Then ask your agent, for example: "Add a photo gallery with a lightbox
to `/gallery`. Photos come from `/api/photos`."

## Point the agent to the docs

Every page has a Markdown version for agents. The complete examples on the
site become code blocks there.

| Source                                                           | Use it for                                  |
| ---------------------------------------------------------------- | ------------------------------------------- |
| [`/llms.txt`](https://nuxt-photo.lupinum.com/llms.txt)           | An index of every page with a description.  |
| `/raw/docs/<page>.md`                                            | One page as Markdown.                       |
| [`/llms-full.txt`](https://nuxt-photo.lupinum.com/llms-full.txt) | All pages in one file, for a large context. |

For example, this page is at
`https://nuxt-photo.lupinum.com/raw/docs/start/ai-agents.md`.

## Connect the MCP server

The docs site runs an MCP server with two read-only tools: `list-pages` and
`get-page`. Add it to an agent that supports remote MCP servers:

```json [.mcp.json]
{
  "mcpServers": {
    "nuxt-photo-docs": {
      "type": "http",
      "url": "https://nuxt-photo.lupinum.com/mcp"
    }
  }
}
```

## Let the types answer first

An agent often reads the installed package before any docs. Every public prop
and `PhotoItem` field has a description in the types, with its default and
whether it can change after mount. Error messages name the fix and link to the
page that explains it. Ask the agent to run your typecheck after a change: most
wrong props and missing fields show up there.

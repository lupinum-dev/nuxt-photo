Build a responsive photo album with one module, one photo collection, and one
component. Each photo includes its intrinsic dimensions, so Nuxt Photo can
render useful geometry on the server before the image downloads.

::info{icon="lucide:package-check"}
If the project still uses `0.1.x`, follow the [0.2 upgrade guide]($docs/resources/upgrade-to-0-2)
before copying the examples;
collection ownership, layout options, and import paths changed.
::

## 1. Install the module

::code-group

```bash [npm]
npm install @nuxt-photo/nuxt
```

```bash [yarn]
yarn add @nuxt-photo/nuxt
```

```bash [pnpm]
pnpm add @nuxt-photo/nuxt
```

```bash [bun]
bun add @nuxt-photo/nuxt
```

```bash [deno]
deno add npm:@nuxt-photo/nuxt
```

::

Read the package manifest for the authoritative Nuxt and Node compatibility ranges.

## 2. Register it

Use the full theme for the first result. You can switch to structure-only CSS
when the gallery is working.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    css: 'all',
  },
})
```

The module registers `Photo`, `PhotoAlbum`, `PhotoGroup`, and `PhotoCarousel`.
It also auto-imports `useLightbox`, `useLightboxProvider`, and `responsive`.

## 3. Render the album

```vue [app/pages/index.vue]
<script setup lang="ts">
import type { PhotoItem } from '@nuxt-photo/nuxt/app'

const photos: PhotoItem[] = [
  {
    id: 'desert',
    src: '/photos/desert.jpg',
    width: 1280,
    height: 800,
    alt: 'Sand dunes at golden hour',
    caption: 'Desert light',
  },
  {
    id: 'coast',
    src: '/photos/coast.jpg',
    width: 960,
    height: 1200,
    alt: 'Rocky coast seen from above',
    caption: 'From above',
  },
  {
    id: 'forest',
    src: '/photos/forest.jpg',
    width: 1200,
    height: 800,
    alt: 'Morning mist between pine trees',
    caption: 'Forest haze',
  },
]
</script>

<template>
  <PhotoAlbum :photos="photos" :layout="{ type: 'rows', targetRowHeight: 240 }" />
</template>
```

Put matching files in `public/photos`, start the app, and select a thumbnail.
The album opens its lightbox by default. Use the arrow keys to navigate and
`Escape` to close it.

## Use real image data

Every item needs a stable string `id`, a `src`, and finite positive `width` and
`height`. The dimensions must match the source image. Invalid data throws at
the component boundary instead of producing an unstable layout.

If the data comes from a CMS, map it to `PhotoItem` once in the loader or
composable. The [CMS gallery guide]($docs/guides/cms-gallery) keeps that mapping
out of the template, while [the photo model]($docs/concepts/photo-model)
documents validation and optional fields.

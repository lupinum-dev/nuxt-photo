---
title: Installation
description: Install the Nuxt module, choose the CSS layer, and optionally connect Nuxt Image.
---

Nuxt apps install `@nuxt-photo/nuxt`. The Vue package is already a dependency,
so app code can use auto-imports or import explicitly from
`@nuxt-photo/nuxt/app`.

## Requirements

The package manifests are the source of truth for supported Nuxt, Node, Vue,
and optional Nuxt Image ranges. Your package manager reports an actionable peer
error when an application falls outside them.

## Add the module

Nuxt can install and register it in one command:

```bash [Terminal]
npx nuxi module add @nuxt-photo/nuxt
```

For a manual setup, install the package and add it to `modules`:

::code-group

```bash [npm]
npm install @nuxt-photo/nuxt
```

```bash [yarn]
yarn add @nuxt-photo/nuxt
```

```bash [pnpm]
pnpm add @nuxt-photo/nuxt
```

```bash [bun]
bun add @nuxt-photo/nuxt
```

```bash [deno]
deno add npm:@nuxt-photo/nuxt
```

::

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
})
```

The default `css: 'structure'` loads the geometry required by albums,
carousels, photos, and the lightbox without applying the complete visual theme.
Use `css: 'all'` while evaluating the library or when the default theme fits
the project.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    css: 'all',
  },
})
```

## Add Nuxt Image

Install `@nuxt/image` only when thumbnails and slides should use its providers
and responsive image generation.

::code-group

```bash [npm]
npm install @nuxt/image
```

```bash [yarn]
yarn add @nuxt/image
```

```bash [pnpm]
pnpm add @nuxt/image
```

```bash [bun]
bun add @nuxt/image
```

```bash [deno]
deno add npm:@nuxt/image
```

::

Register it in the same modules list. In the default `image.provider: 'auto'`
mode, Nuxt Photo detects the registered module after module installation and
uses it. Without `@nuxt/image`, it uses the native adapter.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt', '@nuxt/image'],
  image: {
    domains: ['images.example.com'],
  },
})
```

lightbox minimum zoom. The generated configuration shows which changes require
an app restart.

---
title: Build a carousel
description: Configure horizontal browsing, controls, autoplay, and an optional lightbox.
---

`PhotoCarousel` provides horizontal dragging, snap groups, thumbnails, and
controls without exposing its internal Embla instance.

::carousel-lab
::

## Start with deliberate defaults

```vue [app/components/FeaturedPhotos.vue]
<template>
  <PhotoCarousel
    :photos="photos"
    :options="{ loop: true, slidesToScroll: 1 }"
    slide-aspect="16/9"
    show-thumbnails
    show-counter
    :lightbox="true"
  />
</template>
```

Carousels do not open a lightbox unless `lightbox` is enabled. That option and
the transition are setup-time capabilities; remount the component when a user
setting changes either one.

## Add autoplay only when motion is welcome

```vue [app/components/FeaturedPhotos.vue]
<script setup lang="ts">
const prefersReducedMotion = ref(true)

onMounted(() => {
  prefersReducedMotion.value = window.matchMedia('(prefers-reduced-motion: reduce)').matches
})

const autoplay = computed(() =>
  prefersReducedMotion.value
    ? false
    : {
        delayMs: 4500,
        stopOnInteraction: true,
        stopOnMouseEnter: true,
      },
)
</script>

<template>
  <PhotoCarousel :photos="photos" :autoplay="autoplay" />
</template>
```

Nuxt Photo does not disable autoplay from the reduced-motion media query on
your behalf. Start with autoplay off during SSR, then enable it after mount only
when the reader has not requested reduced motion.

`slidesToScroll` must be a positive integer. The rendered width determines the
actual snap groups, so dots describe snap indexes while the counter and caption
describe the first active photo index. Use the [PhotoCarousel reference]($docs/components/photo-carousel)
for the exact slot contracts.

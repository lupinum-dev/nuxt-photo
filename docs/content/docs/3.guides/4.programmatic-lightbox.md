---
title: Control a lightbox programmatically
description: Open, close, and navigate a provider from application controls or a route.
---

Use a `PhotoGroup` template ref when an outside control only needs to open or
close the collection.

```vue [app/pages/gallery.vue]
<script setup lang="ts">
const group = ref<{
  open(index?: number): Promise<void>
  openById(id: string): Promise<void>
  close(): Promise<void>
}>()
</script>

<template>
  <button type="button" @click="group?.openById('ocean')">Open ocean</button>

  <PhotoGroup ref="group" :photos="photos">
    <PhotoAlbum :photos="photos" />
  </PhotoGroup>
</template>
```

`open()` defaults to index `0`. Invalid indexes and unknown IDs reject with a
`RangeError`; valid calls on a disabled group do nothing.

## Read state inside the provider

`useLightbox()` must run in a descendant of `PhotoGroup` or
`LightboxProvider`. Put stateful controls in a child component rather than in
the same setup function that renders the provider.

```vue [app/components/GalleryControls.vue]
<script setup lang="ts">
const lightbox = useLightbox()
</script>

<template>
  <p v-if="lightbox.activePhoto.value">Viewing {{ lightbox.activePhoto.value.caption }}</p>
  <button type="button" @click="lightbox.prev()">Previous</button>
  <button type="button" @click="lightbox.next()">Next</button>
  <button type="button" @click="lightbox.close()">Close</button>
</template>
```

Navigation loops while the lightbox is open and does nothing while it is
closed. `close()` is idempotent. Await `open`, `openById`, or `close` when route
state must follow the completed lifecycle rather than the initial click.

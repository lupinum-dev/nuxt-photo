---
title: Collections and ownership
description: Keep identity and lightbox navigation in one explicit ordered collection.
---

One lightbox provider owns one ordered photo collection. Layout components supply triggers and optional slide renderers; they do not create a second navigation order.

## A group owns the canonical order

Pass the complete collection to `PhotoGroup`, then render any subset through descendant recipes.

```vue [app/pages/portfolio.vue]
<script setup lang="ts">
const allPhotos = computed(() => [...landscapes.value, ...portraits.value])
</script>

<template>
  <PhotoGroup :photos="allPhotos">
    <section>
      <h2>Landscapes</h2>
      <PhotoAlbum :photos="landscapes" />
    </section>

    <section>
      <h2>Portraits</h2>
      <PhotoAlbum :photos="portraits" />
    </section>
  </PhotoGroup>
</template>
```

Opening the final landscape and moving forward shows the first portrait because `allPhotos` defines that sequence. Reordering the two sections in the DOM does not change it.

## Descendants register capabilities

Grouped `Photo` and `PhotoAlbum` components register their thumbnail elements by photo ID. Nuxt Photo uses those elements for opening and closing transitions while the group continues to own data and navigation.

The group rejects ambiguous states:

- A descendant ID missing from `PhotoGroup.photos` throws.
- Duplicate IDs in the canonical collection throw.
- Two descendants cannot register different custom slide renderers for the same ID.

Set `lightbox-ignore` on an individual `Photo` when it should remain visible but not open the parent lightbox.

## Provider capabilities are setup-time

`lightbox`, `transition`, and `imageAdapter` determine which provider a recipe creates. Changing one after mount does not rebuild that provider. Remount the owner when the configuration itself must change.

```vue [app/components/GalleryMode.vue]
<template>
  <PhotoGroup :key="viewerEnabled ? 'viewer' : 'static'" :photos="photos" :lightbox="viewerEnabled">
    <PhotoAlbum :photos="photos" />
  </PhotoGroup>
</template>
```

Only one provider owns modal focus and page isolation at a time. Opening another Nuxt Photo lightbox closes the current one before transferring ownership.

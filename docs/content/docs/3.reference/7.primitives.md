Lower-level components share the nearest lightbox context. Import them from
`@lupinum/nuxt-photo/primitives`, or `@lupinum/vue-photo/primitives` in plain
Vue. `PhotoImage` is in the stable entry, `@lupinum/nuxt-photo/app`. A
ready-made component provides that context to its custom viewer. For a
standalone composition, wrap triggers and viewer in `LightboxProvider`.

::note
The primitives entry is advanced API. Its components, props and slot props may
change in a minor version; read the changelog before you update.
::

## `LightboxProvider`

Renders its default slot without a wrapper. It provides context but does not
render a viewer. It has no public events or exposed template-ref handle.

| Prop         | Type                                | Default               | Timing and meaning                                             |
| ------------ | ----------------------------------- | --------------------- | -------------------------------------------------------------- |
| `photos`     | `PhotoItem \| readonly PhotoItem[]` | required              | Reactive collection.                                           |
| `transition` | `LightboxTransitionOption`          | inherited (`'auto'`)  | Reactive opening and closing animation.                        |
| `navigation` | `LightboxNavigationMode`            | inherited (`'slide'`) | Reactive photo change mode.                                    |
| `minZoom`    | `number`                            | inherited (`1.5`)     | Setup-time lowest click zoom.                                  |
| `component`  | `Component`                         | inherited / unset     | Accepted configuration key; this provider does not render it.  |
| `validation` | `InvalidPhotoPolicy`                | inherited (`'throw'`) | Reactive invalid photo policy.                                 |
| `history`    | `boolean`                           | inherited (`true`)    | Read when entering or leaving history.                         |
| `deepLink`   | `boolean \| string`                 | inherited (disabled)  | Initial URL read at setup; current value used for URL updates. |
| `tools`      | `LightboxTool[]`                    | inherited (no tools)  | Reactive configuration for the built-in viewer.                |

```vue [app/components/PhotoViewer.vue]
<script setup lang="ts">
import { Lightbox, PhotoImage, type PhotoItem } from '@lupinum/nuxt-photo/app'
import { LightboxProvider, PhotoTrigger } from '@lupinum/nuxt-photo/primitives'
defineProps<{ photos: PhotoItem[] }>()
</script>

<template>
  <LightboxProvider :photos="photos">
    <PhotoTrigger v-for="(photo, index) in photos" :key="photo.id" :photo="photo" :index="index">
      <PhotoImage :photo="photo" />
    </PhotoTrigger>
    <Lightbox />
  </LightboxProvider>
</template>
```

## Viewer primitives

These components emit no public events, expose no public template-ref handle,
and have no `ui` prop. Normal attributes supply classes and accessible names.
Unless listed below, they have no declared props. Their default slots have no
slot props unless the table lists them.

| Component          | Function                                                                                                                                                                                                           | Default slot props                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `LightboxRoot`     | A native `<dialog>`, opened with `showModal()`: the browser keeps focus inside and makes the page inert. Teleports while open, restores focus, and renders the opening animation layer. Supply an accessible name. | none                                                                                                                                                               |
| `LightboxOverlay`  | Backdrop; a click on the overlay itself requests close.                                                                                                                                                            | none                                                                                                                                                               |
| `LightboxAmbient`  | Canvas glow of the current photo; reduced motion removes its crossfade.                                                                                                                                            | none                                                                                                                                                               |
| `LightboxViewport` | Gesture and wheel area. Attach `viewportRef` to the element that clips the slide track. Its first child is the track, and the track's children are the slides in photo order.                                      | `photos: readonly ResolvedPhotoItem[]`, `viewportRef: Ref<HTMLElement \| null \| undefined>`, `imageLoadFailed: boolean`, `isSlideMounted(index: number): boolean` |
| `LightboxSlide`    | Fitted photo frame with zoom and pan wrappers, and an optional caption under the frame.                                                                                                                            | `photo: ResolvedPhotoItem`, `index: number`, `width: number`, `height: number` (fitted pixels)                                                                     |
| `LightboxControls` | Controls wrapper and a polite slide announcement.                                                                                                                                                                  | `LightboxControlsSlotProps` below                                                                                                                                  |
| `LightboxCaption`  | One caption wrapper for the active photo; supplies no text.                                                                                                                                                        | `photo: ResolvedPhotoItem \| null`, `activeIndex: number`                                                                                                          |

`LightboxAmbient` changes with the photo, not after it. A swipe crosses the glow
over by the share of the way the photo has moved, and the release continues on
the photo's settle. Keys, buttons and the `fade` and `crossfade` modes use the
photos' own timing. The glow sits inside `LightboxOverlay`, so an open or close
fades it with the backdrop.

`LightboxAmbient.duration?: number` defaults to `480` milliseconds. It sets only
the linear crossfade of a photo change without motion, such as an index set from
outside. With reduced motion, the glow changes at once.

The glow is painted from the thumbnail the page already shows when that image is
loaded and readable. Otherwise the thumbnail is requested, and the open waits at
most one frame for it. A remote image is requested with CORS first; without CORS
headers it falls back to a stretched image that cannot be blurred from pixel
data. Set `--np-ambient-opacity: 0` to turn the glow off.

### `LightboxSlide` props

| Prop           | Type                | Default  | Timing                                         |
| -------------- | ------------------- | -------- | ---------------------------------------------- |
| `photo`        | `ResolvedPhotoItem` | required | Reactive.                                      |
| `index`        | `number`            | required | Reactive collection position.                  |
| `effectClass`  | `string`            | unset    | Reactive classes for the effect wrapper.       |
| `frameClass`   | `string`            | unset    | Reactive classes for the fitted frame.         |
| `zoomClass`    | `string`            | unset    | Reactive classes for the zoom and pan wrapper. |
| `captionClass` | `string`            | unset    | Reactive classes for the caption wrapper.      |

The default slot replaces image content on the active or leaving slide.
A ready-made component's custom slide renderer is used when there is no default slot.
`isSlideMounted` covers the active photo and one photo in each direction,
wrapping around the collection, plus leaving slides. Keep an equal-width spacer for an unmounted slide to
preserve track positions.

### `LightboxControlsSlotProps`

| Field                                           | Type                           |
| ----------------------------------------------- | ------------------------------ |
| `activeIndex`, `count`                          | `number`                       |
| `activePhoto`                                   | `ResolvedPhotoItem \| null`    |
| `photos`                                        | `readonly ResolvedPhotoItem[]` |
| `isZoomedIn`, `zoomAllowed`, `controlsDisabled` | `boolean`                      |
| `next`, `prev`, `toggleZoom`                    | `() => void`                   |
| `close`                                         | `() => Promise<void>`          |

### Slot-prop types

The primitives entry also exports the slot-prop types: `LightboxControlsSlotProps`,
`LightboxCaptionSlotProps`, `LightboxSlideSlotProps` and
`LightboxViewportSlotProps`. Each takes the `TMeta` type argument of
[`PhotoItem`](/docs/reference/types). `LightboxSlideSlotProps.width` and
`height` are fitted frame pixels.

```ts
import type { LightboxCaptionSlotProps } from '@lupinum/nuxt-photo/primitives'
```

## Choose a caption primitive

| Use                        | When                                                                                                                                     |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `LightboxSlide` `#caption` | The caption belongs under its photo. It renders inside the slide frame, moves with the photo in a swipe and fades with it in fade modes. |
| `LightboxCaption`          | One caption for the active photo in a fixed place, such as a side panel or a bar at the bottom of the screen.                            |

The `#caption` slot of `LightboxSlide` gets `{ photo, index }` for that slide's
photo. Its wrapper has `data-np-slide-caption`; the structure CSS places it
under the frame, aligned to the photo's left edge, at least 320 pixels wide and
inside the slide. Only the active slide's caption is exposed to assistive
technology. A tap on a caption neither closes the lightbox nor zooms. Both
primitives hide while the photo is zoomed, and fade with the controls on open,
on close, and during a drag down.

## `PhotoTrigger`

Renders a native button with `data-np-photo-id`, which the lightbox uses to
find the thumbnail. Click, Enter, and Space open its index. Its default
slot receives `{ photo: PhotoItem, index: number, hidden: boolean }`.
`hidden` is true while the animation represents the thumbnail.

| Prop    | Type        | Default  | Timing                                        |
| ------- | ----------- | -------- | --------------------------------------------- |
| `photo` | `PhotoItem` | required | Reactive photo and accessible label.          |
| `index` | `number`    | required | Reactive position in the provider collection. |

It has no public events, exposed handle, or `ui` prop. Its built-in class is
`.np-trigger`. Do not nest another interactive element inside the button.

## `PhotoImage`

Renders an image through the configured provider. It validates its photo
strictly, including dimensions. A placeholder remains visible after a failed
request. It has no slots, public events, exposed handle, or `ui` prop. Native
image attributes and event listeners are forwarded to the image.

| Prop       | Type                      | Default            | Timing and meaning                              |
| ---------- | ------------------------- | ------------------ | ----------------------------------------------- |
| `photo`    | `PhotoItem`               | required           | Reactive.                                       |
| `context`  | `'thumb' \| 'slide'`      | `'thumb'`          | Reactive image context.                         |
| `provider` | `PhotoProvider \| string` | inherited          | Reactive; a name requires Nuxt Image.           |
| `priority` | `boolean`                 | `false`            | Reactive; eager image with high fetch priority. |
| `sizes`    | `string`                  | `'100vw'` fallback | Reactive; layout hint, independent of provider. |

A non-priority image is lazy and prefixes its sizes with `auto, ` unless they
already start with `auto`. Pass the album thumbnail slot's `sizes` and
`priority` to this component.

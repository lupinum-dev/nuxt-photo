Lower-level components share the nearest lightbox context. Import them from
`@lupinum/nuxt-photo/app`. A ready-made component provides that context to its
custom viewer. For a standalone composition, wrap triggers and viewer in
`LightboxProvider`.

## `LightboxProvider`

Renders its default slot without a wrapper. It provides context but does not
render a viewer. It has no public events or exposed template-ref handle.

| Prop | Type | Default | Timing and meaning |
| --- | --- | --- | --- |
| `photos` | `PhotoItem \| readonly PhotoItem[]` | required | Reactive collection. |
| `transition` | `LightboxTransitionOption` | inherited (`'auto'`) | Reactive opening and closing animation. |
| `navigation` | `LightboxNavigationMode` | inherited (`'slide'`) | Reactive photo change mode. |
| `minZoom` | `number` | inherited (`1.5`) | Setup-time lowest click zoom. |
| `component` | `Component` | inherited / unset | Accepted configuration key; this provider does not render it. |
| `validation` | `InvalidPhotoPolicy` | inherited (`'throw'`) | Reactive invalid photo policy. |
| `history` | `boolean` | inherited (`true`) | Read when entering or leaving history. |
| `deepLink` | `boolean \| string` | disabled | Initial URL read at setup; current value used for URL updates. |
| `tools` | `LightboxTool[]` | no tools | Reactive configuration for the built-in viewer. |

```vue [app/components/PhotoViewer.vue]
<script setup lang="ts">
import { Lightbox, LightboxProvider, PhotoImage, PhotoTrigger, type PhotoItem } from '@lupinum/nuxt-photo/app'
defineProps<{ photos: PhotoItem[] }>()
</script>

<template>
  <LightboxProvider :photos="photos">
    <PhotoTrigger v-for="(photo, index) in photos" :key="photo.id" :photo="photo" :index="index">
      <PhotoImage :photo="photo" />
    </PhotoTrigger>
    <Lightbox />
  </LightboxProvider>
</template>
```

## Viewer primitives

These components emit no public events, expose no public template-ref handle,
and have no `ui` prop. Normal attributes supply classes and accessible names.
Unless listed below, they have no declared props. Their default slots have no
slot props unless the table lists them.

| Component | Function | Default slot props |
| --- | --- | --- |
| `LightboxRoot` | Teleports while open, traps focus, isolates the page, restores focus, and renders the opening animation layer. Supply `role="dialog"`, `aria-modal="true"`, and an accessible name. | none |
| `LightboxOverlay` | Backdrop; a click on the overlay itself requests close. | none |
| `LightboxAmbient` | Canvas glow of the current photo; reduced motion removes its crossfade. | none |
| `LightboxViewport` | Gesture and wheel area. Attach `viewportRef` to the element that clips the slide track. | `photos: readonly PhotoItem[]`, `viewportRef: Ref<HTMLElement \| null \| undefined>`, `imageLoadFailed: boolean`, `isSlideMounted(index: number): boolean` |
| `LightboxSlide` | Fitted photo frame with zoom and pan wrappers. | `photo: PhotoItem`, `index: number`, `width: number`, `height: number` (fitted pixels) |
| `LightboxControls` | Controls wrapper and a polite slide announcement. | `LightboxControlsSlotProps` below |
| `LightboxCaption` | Caption wrapper; supplies no text. | `photo: PhotoItem \| null`, `activeIndex: number` |

`LightboxAmbient.duration?: number` defaults to `480` milliseconds and is
reactive for subsequent fades. A remote image is requested with CORS first;
without CORS headers it falls back to a stretched image that cannot be blurred
from pixel data.

### `LightboxSlide` props

| Prop | Type | Default | Timing |
| --- | --- | --- | --- |
| `photo` | `PhotoItem` | required | Reactive. |
| `index` | `number` | required | Reactive collection position. |
| `effectClass` | `string` | unset | Reactive classes for the effect wrapper. |
| `frameClass` | `string` | unset | Reactive classes for the fitted frame. |
| `zoomClass` | `string` | unset | Reactive classes for the zoom and pan wrapper. |

The default slot replaces image content on the active or leaving slide.
A recipe's custom slide renderer is used when there is no default slot.
`isSlideMounted` covers a circular window of three photos in each direction,
plus leaving slides. Keep an equal-width spacer for an unmounted slide to
preserve track positions.

### `LightboxControlsSlotProps`

| Field | Type |
| --- | --- |
| `activeIndex`, `count` | `number` |
| `activePhoto` | `PhotoItem \| null` |
| `photos` | `readonly PhotoItem[]` |
| `isZoomedIn`, `zoomAllowed`, `controlsDisabled` | `boolean` |
| `next`, `prev`, `toggleZoom` | `() => void` |
| `close` | `() => Promise<void>` |

## `PhotoTrigger`

Renders a native button. Click, Enter, and Space open its index. Its default
slot receives `{ photo: PhotoItem, index: number, hidden: boolean }`.
`hidden` is true while the animation represents the thumbnail.

| Prop | Type | Default | Timing |
| --- | --- | --- | --- |
| `photo` | `PhotoItem` | required | Reactive photo and accessible label. |
| `index` | `number` | required | Reactive position in the provider collection. |

It has no public events, exposed handle, or `ui` prop. Its built-in class is
`.np-trigger`. Do not nest another interactive element inside the button.

## `PhotoImage`

Renders an image through the configured provider. It validates its photo
strictly, including dimensions. A placeholder remains visible after a failed
request. It has no slots, public events, exposed handle, or `ui` prop. Native
image attributes and event listeners are forwarded to the image.

| Prop | Type | Default | Timing and meaning |
| --- | --- | --- | --- |
| `photo` | `PhotoItem` | required | Reactive. |
| `context` | `'thumb' \| 'slide'` | `'thumb'` | Reactive image context. |
| `provider` | `PhotoProvider \| string` | inherited | Reactive; a name requires Nuxt Image. |
| `priority` | `boolean` | `false` | Reactive; eager image with high fetch priority. |
| `sizes` | `string` | `'100vw'` fallback | Reactive; layout hint, independent of provider. |

A non-priority image is lazy and prefixes its sizes with `auto, ` unless they
already start with `auto`. Pass the album thumbnail slot's `sizes` and
`priority` to this component.

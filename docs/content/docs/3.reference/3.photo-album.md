`PhotoAlbum` lays out one photo collection. Selecting a thumbnail opens the
included lightbox unless the lightbox is disabled or owned by a parent group.

## Minimal usage

```vue [app/pages/gallery.vue]
<script setup lang="ts">
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

const photos: PhotoItem[] = [
  { id: 'one', src: '/photos/one.jpg', width: 1200, height: 800, alt: 'Mountain valley' },
  { id: 'two', src: '/photos/two.jpg', width: 800, height: 1200, alt: 'Forest path' },
]
</script>

<template>
  <PhotoAlbum :photos="photos" layout="rows" />
</template>
```

## Props

`active` is optional (`string | null`, default `undefined`) and reactive.
`v-model:active` sets the lightbox photo ID; `null` closes it. User navigation
emits `update:active`. An unknown ID is ignored with a development warning.

`lightbox` accepts `boolean | LightboxOptions`. Its enabled state and
`component` are setup-time: remount with a new `key` to change them.
The options inherit [configuration defaults](/docs/reference/configuration-and-labels).
`minZoom` is setup-time. Other lightbox options are read reactively; changing
`deepLink` does not repeat the initial URL lookup.

| Prop                    | Type                                              | Default                 | Description                                                        |
| ----------------------- | ------------------------------------------------- | ----------------------- | ------------------------------------------------------------------ |
| `photos`                | `readonly PhotoItem[]`                            | -                       | **Required.** Ordered photos to render.                            |
| `validation`            | `'throw' \| 'drop'`                               | inherited (`'throw'`) | Invalid collection policy.                                         |
| `layout`                | `'rows' \| 'columns' \| 'masonry' \| AlbumLayout` | `'rows'`                | Layout type and its options.                                       |
| `spacing`               | `ResponsiveParameter<number>`                     | `8`                     | Gap between items in pixels.                                       |
| `padding`               | `ResponsiveParameter<number>`                     | `0`                     | Padding around each item in pixels.                                |
| `defaultContainerWidth` | `number`                                          | -                       | Assumed server-side container width.                               |
| `breakpoints`           | `readonly number[]`                               | derived                 | Width snap points; derived from `responsive()` when omitted.       |
| `sizes`                 | `string \| ResponsivePhotoSizes`                  | -                       | Native or rows-layout-aware image `sizes` hint.                    |
| `priority`              | `number`                                          | `0`                     | Number of leading photos to load eagerly with high fetch priority. |
| `lightbox`              | `boolean \| LightboxOptions`                            | `true`                  | Enable, disable, or replace the lightbox.                          |
| `active` | `string \| null` | `undefined` | Lightbox photo ID; reactive. |
| `provider` | `PhotoProvider \| string` | inherited | Image delivery; reactive. A name requires Nuxt Image. |
| `ui` | `PhotoUi<'PhotoAlbum'>` | `undefined` | Classes merged onto built-in classes; reactive. |

Rows layout accepts `targetRowHeight` and defaults it to `300`. Columns and
masonry accept `columns` and default it to `3`. These values may use
`ResponsiveParameter<number>`.

## Events

| Event           | Payload              | When it fires                                               |
| --------------- | -------------------- | ----------------------------------------------------------- |
| `invalidPhotos` | `InvalidPhotosEvent` | Invalid entries are found while `validation="drop"` is set. |
| `update:active` | `string \| null` | Lightbox opens, navigates, or closes. |
| `end-reached` | none | End sentinel is within one viewport of the screen. Fires once per collection length; adding photos permits another emission. |

```vue [app/components/ValidatedAlbum.vue]
<script setup lang="ts">
import type { InvalidPhotosEvent, PhotoItem } from '@lupinum/nuxt-photo/app'

defineProps<{ photos: readonly PhotoItem[] }>()

function reportInvalidPhotos(event: InvalidPhotosEvent) {
  console.warn('Invalid photos:', event.issues)
}
</script>

<template>
  <PhotoAlbum :photos="photos" validation="drop" @invalid-photos="reportInvalidPhotos" />
</template>
```

## Slots

| Slot        | Props                                     | Purpose                         |
| ----------- | ----------------------------------------- | ------------------------------- |
| `thumbnail` | `{ photo, index, width, height, hidden, sizes, priority }` | Replace each thumbnail content. |

`hidden` becomes `true` while the selected thumbnail is represented by the
opening or closing animation. Pass `sizes` and `priority` to `PhotoImage` inside a custom thumbnail to keep
the layout hints and configured provider.

## Exposed template-ref API

The exposed `GalleryHandle` has `open(index?: number): Promise<void>`,
`openById(id: string): Promise<void>`, and `close(): Promise<void>`.
`open()` defaults to index `0`. Its readonly state is `isOpen: boolean`,
`activeId: string | null`, and `activePhoto: PhotoItem | null`.

Inside `PhotoGroup`, a local index is translated to the photo ID.

## Important behavior

- Rows produce justified photo rows. Columns keep a fixed column count.
  Masonry places each next photo in the shortest column.
- Layout options, photos, provider, validation, priority, ui, and responsive values are
  reactive.
- `lightbox` is setup-time. Remount with a new `key` to add, remove, or replace it.
- A parent `PhotoGroup` owns the lightbox and navigation collection.
- Incorrect dimensions can produce incorrect layout and transition geometry.

## Responsive columns

```vue
<PhotoAlbum
  :photos="photos"
  :layout="{
    type: 'columns',
    columns: responsive({ 0: 2, 640: 3, 1024: 4 }),
  }"
  :spacing="responsive({ 0: 4, 640: 8, 1024: 12 })"
/>
```

Nuxt auto-imports `responsive()`. Plain Vue applications import it from
`@lupinum/vue-photo`.

Use [Responsive layouts and SSR](/docs/guides/responsive-layouts) for layout
decisions and [server rendering](/docs/guides/responsive-layouts#prevent-a-layout-jump-after-server-rendering)
for `defaultContainerWidth` and hydration behavior.

## Class targets and reactivity

`ui` keys: `root`, `item`, `img`.
All props other than lightbox capability, its component, and `minZoom` are
reactive, except `defaultContainerWidth`, which seeds setup-time measurement.

The thumbnail slot receives `photo: PhotoItem`, zero-based `index: number`,
`width: number`, `height: number` (layout pixels), `hidden: boolean`,
`sizes?: string`, and `priority?: boolean`. A missing dimension must resolve
from configuration before layout; incorrect dimensions produce incorrect
geometry. The end sentinel requires IntersectionObserver in the browser.

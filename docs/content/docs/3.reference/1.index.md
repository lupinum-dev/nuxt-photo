Look up an exact name, type, default, event, slot, or import here. For a
complete task, start with the [guides](/docs/guides/use-your-photos). Your
editor shows the same prop descriptions on hover, from the package types.

## Components

- [`Photo`](/docs/reference/photo): one photo, with an optional lightbox.
- [`PhotoAlbum`](/docs/reference/photo-album): rows, columns, or masonry with a lightbox.
- [`PhotoGroup`](/docs/reference/photo-group): one lightbox order across several sections.
- [`PhotoCarousel`](/docs/reference/photo-carousel): horizontal browsing with thumbnails.
- [`Lightbox`](/docs/reference/lightbox): the built-in viewer, its slots, keyboard, and gestures.
- [Primitives](/docs/reference/primitives): lower-level components for your own lightbox.

## APIs

- [Composables](/docs/reference/composables): lightbox state, labels, local folders, validation, providers, and `responsive`.
- [Configuration and labels](/docs/reference/configuration-and-labels): every `nuxtPhoto` option.
- [Types](/docs/reference/types): `PhotoItem`, providers, configuration, handles, controllers, and slot props.
- [CSS](/docs/reference/css): classes and CSS variables.
- [Package exports](/docs/reference/package-exports): the supported import paths.

The package source and its type tests own these facts. The docs build checks
the component, option, CSS, and export names on these pages against the source.

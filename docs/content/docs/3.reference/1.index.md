## Components

- [`Photo`](/docs/reference/photo) renders one photo.
- [`PhotoAlbum`](/docs/reference/photo-album) lays out a photo collection.
- [`PhotoGroup`](/docs/reference/photo-group) gives several sections one
  collection and lightbox.
- [`PhotoCarousel`](/docs/reference/photo-carousel) provides horizontal browsing.
- [`Lightbox`](/docs/reference/lightbox) is the ready-made viewer component.
- [Primitives](/docs/reference/primitives) are lower-level lightbox components.

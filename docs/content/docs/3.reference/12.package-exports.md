title: Package exports

---

Use only the public entry points in the first table. Source folders, generated
files and the [internal entries](#internal-entries) are not application
imports.

| Entry point                        | Purpose                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `@lupinum/vue-photo`               | Plain Vue components, helpers, and types.                                      |
| `@lupinum/vue-photo/primitives`    | Lightbox primitives for your own viewer. Advanced API.                         |
| `@lupinum/vue-photo/styles.css`    | Complete structure and theme CSS.                                              |
| `@lupinum/vue-photo/lightbox.css`  | Lightbox structure and theme CSS only, for a viewer from primitives.           |
| `@lupinum/vue-photo/styles/*`      | One stylesheet of `styles.css`, see [single stylesheets](#single-stylesheets). |
| `@lupinum/nuxt-photo`              | Nuxt module.                                                                   |
| `@lupinum/nuxt-photo/app`          | Application API, including usePhotoFolder.                                     |
| `@lupinum/nuxt-photo/primitives`   | The Vue primitives entry, for Nuxt apps. Advanced API.                         |
| `@lupinum/nuxt-photo/lightbox.css` | Lightbox structure and theme CSS, for a viewer from primitives.                |
| `@lupinum/vue-photo/agent-docs`    | Docs for coding agents, see [AI coding agents](/docs/start/ai-agents).         |
| `@lupinum/nuxt-photo/agent-docs`   | Docs for coding agents, see [AI coding agents](/docs/start/ai-agents).         |

## Vue root runtime exports

```text [Runtime exports]
Lightbox,
Photo,
PhotoAlbum,
PhotoCarousel,
PhotoGroup,
PhotoImage,
PhotoValidationError,
createPhoto,
definePhotoProvider,
validatePhotos,
responsive,
useLightbox,
usePhotoLabels
```

These are the complete runtime exports. The [types reference](/docs/reference/types)
lists the complete type-only exports.

```ts [app/main.ts]
import { createPhoto, PhotoAlbum, responsive, type PhotoItem } from '@lupinum/vue-photo'
import '@lupinum/vue-photo/styles.css'
```

## Primitives entry

`@lupinum/vue-photo/primitives` and `@lupinum/nuxt-photo/primitives` export the
same names. It is advanced API: it may change in a minor version, while the
root entry follows semantic versioning.

```text [Primitives exports]
LightboxAmbient,
LightboxCaption,
LightboxControls,
LightboxOverlay,
LightboxProvider,
LightboxRoot,
LightboxSlide,
LightboxViewport,
PhotoTrigger,
type LightboxCaptionSlotProps,
type LightboxControlsSlotProps,
type LightboxSlideSlotProps,
type LightboxViewportSlotProps
```

```ts [app/components/PhotoViewer.vue]
import { Lightbox, PhotoImage } from '@lupinum/nuxt-photo/app'
import { LightboxProvider, PhotoTrigger } from '@lupinum/nuxt-photo/primitives'
```

## Single stylesheets

`@lupinum/vue-photo/styles.css` contains these files in this order. Import single
files to load only the structure, or only one component's CSS.

```text [Stylesheets]
styles/lightbox.css (imports the next two)
styles/lightbox-structure.css
styles/lightbox-theme.css
styles/album.css
styles/photo-structure.css
styles/photo.css
styles/carousel-structure.css
styles/carousel-theme.css
```

```ts [app/main.ts]
import '@lupinum/vue-photo/styles/album.css'
import '@lupinum/vue-photo/styles/photo-structure.css'
```

## Nuxt module root

The only runtime export is `default`, the Nuxt module. The only type-only
export is `NuxtPhotoOptions`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-photo'],
})
```

## Nuxt application exports

`@lupinum/nuxt-photo/app` re-exports every Vue root runtime and type-only
export above, and adds exactly one runtime export: `usePhotoFolder`.
Use this entry point for explicit Nuxt app imports.

```ts [app/utils/gallery.ts]
import { responsive, type PhotoItem } from '@lupinum/nuxt-photo/app'
export const columns = responsive({ 0: 2, 640: 3 })
```

Nuxt registers Photo, PhotoAlbum, PhotoGroup, and PhotoCarousel by default.
Its default auto-imports are useLightbox, usePhotoLabels, usePhotoFolder, and
responsive. Lightbox must be imported explicitly. Lower-level components
are auto-registered only with `components: { primitives: true }`; otherwise
import them from `@lupinum/nuxt-photo/primitives`.

## Internal entries

`@lupinum/nuxt-photo` uses these entries of `@lupinum/vue-photo` of the same
version. They are not public API: semantic versioning does not cover them, and
any release can change them. Do not import them in an app.

| Entry point                           | Used for                                                                 |
| ------------------------------------- | ------------------------------------------------------------------------ |
| `@lupinum/vue-photo/internal`         | The setup functions of the Nuxt plugin.                                  |
| `@lupinum/vue-photo/locales/photo`    | The album and carousel labels. Nuxt keeps only the languages of the app. |
| `@lupinum/vue-photo/locales/viewer`   | The viewer labels. Nuxt keeps only the languages of the app.             |
| `@lupinum/vue-photo/viewer`           | The lazy viewer. Nuxt replaces it with the viewer for its `css` option.  |
| `@lupinum/vue-photo/viewer-structure` | The viewer with the lightbox structure CSS.                              |
| `@lupinum/vue-photo/viewer-themed`    | The viewer with the lightbox structure and theme CSS.                    |

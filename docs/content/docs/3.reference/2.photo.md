---
title: Photo
description: The Photo component - props, slots, and behavior for one photo with an optional one-photo lightbox, alone or inside a PhotoGroup.
---

`Photo` renders one `PhotoItem` as a figure. It can remain a plain image, open a
one-photo lightbox, or connect to a parent `PhotoGroup`.

## Minimal usage

```vue [app/pages/cover.vue]
<script setup lang="ts">
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

const cover: PhotoItem = {
  id: 'cover',
  src: '/photos/cover.jpg',
  width: 1280,
  height: 800,
  alt: 'Low hills under an evening sky',
}
</script>

<template>
  <Photo :photo="cover" lightbox />
</template>
```

## Props

`active` is optional (`string | null`, default `undefined`) and reactive.
`v-model:active` sets the lightbox photo ID; `null` closes it. User navigation
emits `update:active`. An unknown ID is ignored with a development warning.

`lightbox` accepts `boolean | LightboxOptions`. Its enabled state and
`component` are setup-time: remount with a new `key` to change them.
The options inherit [configuration defaults](/docs/reference/configuration-and-labels).
`minZoom` is setup-time. Other lightbox options are read reactively; changing
`deepLink` does not repeat the initial URL lookup.

| Prop             | Type                         | Default               | Description                                                                        |
| ---------------- | ---------------------------- | --------------------- | ---------------------------------------------------------------------------------- |
| `photo`          | `PhotoItem`                  | -                     | **Required.** Photo to render. Uses the validation policy.                         |
| `lightbox`       | `boolean \| LightboxOptions` | `undefined`           | Enable or replace a standalone lightbox. Ignored inside `PhotoGroup`.              |
| `lightboxIgnore` | `boolean`                    | `false`               | Make this trigger inert inside `PhotoGroup` without changing the collection.       |
| `priority`       | `boolean`                    | `false`               | Load eagerly with high fetch priority.                                             |
| `sizes`          | `string`                     | `'100vw'`             | Width on screen as an HTML `sizes` value. Set it when the photo is not full width. |
| `active`         | `string \| null`             | `undefined`           | Lightbox photo ID; reactive.                                                       |
| `provider`       | `PhotoProvider \| string`    | inherited             | Image delivery; reactive. A name requires Nuxt Image.                              |
| `ui`             | `PhotoUi<'Photo'>`           | `undefined`           | Classes merged onto built-in classes; reactive.                                    |
| `validation`     | `'throw' \| 'drop'`          | inherited (`'throw'`) | Invalid photo policy; reactive. Dropping the photo renders no figure.              |

## Events

`Photo` emits `update:active` with its ID or `null`, and `invalidPhotos` with
`InvalidPhotosEvent` when `validation="drop"` rejects its photo.

## Slots

| Slot    | Props              | Purpose                                      |
| ------- | ------------------ | -------------------------------------------- |
| `slide` | `{ photo, index }` | Replace this photo's lightbox slide content. |

## Exposed template-ref API

The exposed `GalleryHandle` has `open(index?: number): Promise<void>`,
`openById(id: string): Promise<void>`, and `close(): Promise<void>`.
`open()` defaults to index `0`. Its readonly state is `isOpen: boolean`,
`activeId: string | null`, and `activePhoto: PhotoItem | null`.

`open()` accepts index `0`; `openById()` accepts this photo's ID.

## Important behavior

- Without `lightbox` or a parent group, the figure is not interactive.
- With `lightbox`, the photo owns a standalone one-item viewer.
- Inside `PhotoGroup`, stable photo ID connects the trigger to the group's
  collection and navigation order.
- `lightbox` is a setup-time option. Remount `Photo` with a new `key` to add,
  remove, or replace the standalone lightbox.
- `photo`, `active`, `provider`, `validation`, `priority`, `sizes`, `ui`, and `lightboxIgnore` are reactive. A `priority` photo without `sizes` keeps `100vw` after the page loads, so its preload and image request the same file.

## Plain image inside a group

```vue
<PhotoGroup :photos="photos">
  <Photo :photo="photos[0]" />
  <Photo :photo="photos[1]" lightbox-ignore />
</PhotoGroup>
```

The second photo remains in programmatic group navigation, but its rendered
thumbnail does not open the lightbox.

[Pick a component](/docs/start/introduction#pick-a-component) compares the
ready-made components. [PhotoGroup](/docs/reference/photo-group) defines shared
collection behavior.

## Class targets and reactivity

`ui` keys: `root`, `img`, `caption`.
Collection data and class targets can change after mount.

The `slide` slot receives `photo: PhotoItem` and a zero-based `index: number`.

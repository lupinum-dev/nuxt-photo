`PhotoCarousel` provides one slide per snap. Its lightbox is off by default.

## Minimal usage

```vue [app/pages/carousel.vue]
<script setup lang="ts">
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

const photos: PhotoItem[] = [
  { id: 'one', src: '/photos/one.jpg', width: 1200, height: 800, alt: 'Rocky coast' },
  { id: 'two', src: '/photos/two.jpg', width: 1200, height: 800, alt: 'Calm sea' },
]
</script>

<template>
  <PhotoCarousel :photos="photos" />
</template>
```

## Props

`active` is optional (`string | null`, default `undefined`) and reactive.
`v-model:active` sets the lightbox photo ID; `null` closes it. User navigation
emits `update:active`. An unknown ID is ignored with a development warning.
It does not control the carousel's inline track.

`lightbox` accepts `boolean | LightboxOptions`. Its enabled state and
`component` are setup-time: remount with a new `key` to change them.
The options inherit [configuration defaults](/docs/reference/configuration-and-labels).
`minZoom` is setup-time. Other lightbox options are read reactively; changing
`deepLink` does not repeat the initial URL lookup.

| Prop          | Type                                      | Default                               | Description                                                                               |
| ------------- | ----------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------- |
| `photos`      | `readonly PhotoItem[]`                    | -                                     | **Required.** Ordered slides.                                                             |
| `validation`  | `'throw' \| 'drop'`                       | inherited (`'throw'`)                 | Invalid collection policy.                                                                |
| `loop`        | `boolean`                                 | `false`                               | Continue from the final slide to the first.                                               |
| `dragFree`    | `boolean`                                 | `false`                               | Allow the track to stop between snap points.                                              |
| `autoplay`    | `boolean \| PhotoCarouselAutoplayOptions` | `false`                               | Enable autoplay.                                                                          |
| `slideSize`   | `string`                                  | -                                     | CSS `flex-basis` for each slide.                                                          |
| `slideAspect` | `string`                                  | -                                     | CSS `aspect-ratio` for each slide.                                                        |
| `gap`         | `string`                                  | -                                     | CSS gap between slides.                                                                   |
| `thumbSize`   | `string`                                  | -                                     | Thumbnail height. The width follows the photo's aspect ratio.                             |
| `lightbox`    | `boolean \| LightboxOptions`              | `false`                               | Enable or replace the optional lightbox.                                                  |
| `active`      | `string \| null`                          | `undefined`                           | Lightbox photo ID; reactive.                                                              |
| `provider`    | `PhotoProvider \| string`                 | inherited                             | Image delivery; reactive. A name requires Nuxt Image.                                     |
| `ui`          | `PhotoUi<'PhotoCarousel'>`                | `undefined`                           | Classes merged onto built-in classes; reactive.                                           |
| `controls`    | `CarouselControl[]`                       | `['arrows', 'thumbnails', 'counter']` | Built-in controls to render; reactive. Values: `arrows`, `dots`, `counter`, `thumbnails`. |

## Events

| Event           | Payload              | When it fires                                               |
| --------------- | -------------------- | ----------------------------------------------------------- |
| `invalidPhotos` | `InvalidPhotosEvent` | Invalid entries are found while `validation="drop"` is set. |
| `update:active` | `string \| null`     | Lightbox opens, navigates, or closes.                       |

```vue
<PhotoCarousel :photos="photos" validation="drop" @invalid-photos="reportInvalidPhotos" />
```

## Slots

| Slot       | Props                                                                              | Purpose                              |
| ---------- | ---------------------------------------------------------------------------------- | ------------------------------------ |
| `slide`    | `{ photo, index, selected, open }`                                                 | Replace each main slide.             |
| `thumb`    | `{ photo, index, selected, goTo }`                                                 | Replace each thumbnail.              |
| `caption`  | `{ photo, index, count }`                                                          | Replace the caption.                 |
| `controls` | `{ goToPrev, goToNext, canGoToPrev, canGoToNext, selectedIndex, snapCount, goTo }` | Replace the complete control block.  |
| `prev`     | -                                                                                  | Replace the previous-button content. |
| `next`     | -                                                                                  | Replace the next-button content.     |
| `dots`     | `{ snaps, selectedIndex, goTo }`                                                   | Replace the dot indicators.          |

Custom `slide` and `thumb` slots replace provider-backed image content. Render
`PhotoImage` inside the slot to keep the configured provider.

## Exposed template-ref API

The exposed `GalleryHandle` has `open(index?: number): Promise<void>`,
`openById(id: string): Promise<void>`, and `close(): Promise<void>`.
`open()` defaults to index `0`. Its readonly state is `isOpen: boolean`,
`activeId: string | null`, and `activePhoto: PhotoItem | null`.

The inline track also exposes `scrollTo(index: number): void`, `next(): void`,
and `prev(): void`. These do not open the lightbox.

## Important behavior

- The carousel uses documented Embla behavior internally, with one slide per snap.
- `loop`, `dragFree`, visual options, and autoplay are reactive.
- Direction comes from the gallery root's computed CSS at mount and at each
  lightbox open. Remount the inline track when its direction changes.
- Main and thumbnail rails use the same direction.
- `lightbox` is setup-time. Remount with a new `key` to add, remove, or replace it.
- Arrow, thumbnail, dot, and pause buttons use the configured localization labels.
- With autoplay, a pause and play button (`.np-carousel__autoplay`) comes first
  in the tab order. Autoplay does not run while the reader prefers reduced
  motion, and the counter's live region is silent while slides change on their own.

## Autoplay options

```ts
interface PhotoCarouselAutoplayOptions {
  delayMs?: number
  stopOnInteraction?: boolean
  stopOnMouseEnter?: boolean
}
```

`delayMs` defaults to `4000`, `stopOnInteraction` to `true`, and
`stopOnMouseEnter` to `false`. `delayMs` must be a positive finite number.

```vue
<PhotoCarousel
  :photos="photos"
  loop
  :autoplay="{
    delayMs: 5000,
    stopOnInteraction: false,
    stopOnMouseEnter: true,
  }"
/>
```

[Build a carousel](/docs/guides/build-a-carousel) covers practical setup.
[Lightbox behavior](/docs/reference/lightbox#keyboard-controls)
lists keyboard and reduced-motion behavior.

## Class targets and reactivity

`ui` keys: `root`, `slide`, `img`, `thumb`, `caption`, `controls`.
Collection data and class targets can change after mount.

Slot photo values are `PhotoItem`; indexes, counts, selectedIndex, and snapCount
are numbers. `selected`, `canGoToPrev`, and `canGoToNext` are booleans.
`open(): void | Promise<void>` opens that slide's lightbox when enabled.
`goTo(index: number): void`, `goToPrev(): void`, and `goToNext(): void` control
the inline track. `snaps` is `readonly number[]`. The first inline slide has
high image priority; other slides use lazy requests. Replacing the slide or
thumb slot also replaces those built-in image hints.

Configure a Nuxt app with `nuxtPhoto` in `nuxt.config.ts`. Plain Vue apps
install the `createPhoto(PhotoConfig)` plugin.

## Plain Vue configuration

`createPhoto(config: PhotoConfig): Plugin` validates configuration before
installation. Unknown keys and invalid values throw `TypeError`. All keys
are optional.

| Key          | Type                                                              | Default         |
| ------------ | ----------------------------------------------------------------- | --------------- |
| `provider`   | `PhotoProvider`                                                   | Native provider |
| `labels`     | `PhotoLocale \| Partial<PhotoLabels>`                             | Detected locale |
| `lightbox`   | `LightboxOptions`                                                 | Defaults below  |
| `validation` | `'throw' \| 'drop'`                                               | `'throw'`       |
| `dimensions` | `(src: string) => { width: number; height: number } \| undefined` | No resolver     |

Pass the plugin to `app.use(createPhoto(config))` before mounting. The
`dimensions` resolver fills both dimensions only when both are missing or
null. Explicit values are preserved; a partial or invalid dimension still
fails validation. Label function keys accept functions in Vue configuration.

## Nuxt module options

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-photo'],
  nuxtPhoto: {
    css: 'all',
    labels: 'de',
    lightbox: { tools: ['download'], deepLink: true },
  },
})
```

| Key           | Type                                                        | Default                                                   | Meaning                                                                                                               |
| ------------- | ----------------------------------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `css`         | `'none' \| 'structure' \| 'all'`                            | `'structure'`                                             | No CSS, layout CSS, or layout plus theme.                                                                             |
| `components`  | `boolean \| { prefix?: string; primitives?: boolean }`      | `{ prefix: '' }`                                          | Register Photo, PhotoAlbum, PhotoGroup, PhotoCarousel. Primitives are off unless enabled. Lightbox stays import-only. |
| `autoImports` | `boolean \| { prefix?: string }`                            | `true`                                                    | Register useLightbox, usePhotoLabels, usePhotoFolder, responsive.                                                     |
| `localImages` | `boolean`                                                   | `false`                                                   | Send the public image dimension lookup to the client.                                                                 |
| `labels`      | `PhotoLocale \| Partial<Record<keyof PhotoLabels, string>>` | Detected locale                                           | Locale or per-label strings and templates.                                                                            |
| `lightbox`    | `LightboxOptions`                                           | No module override                                        | Shared viewer options below.                                                                                          |
| `validation`  | `'throw' \| 'drop'`                                         | `'throw'`                                                 | Shared invalid photo policy.                                                                                          |
| `provider`    | `string`                                                    | Nuxt Image default provider, or native without Nuxt Image | Select a named Nuxt Image provider. Requires `@nuxt/image`.                                                           |

Module options are build/setup configuration. `components: false` and
`autoImports: false` disable registration. A component prefix `Np` produces
`NpPhoto`, `NpPhotoAlbum`, `NpPhotoGroup`, and `NpPhotoCarousel`. An auto-import
prefix `Np` produces `useNpLightbox`, `useNpPhotoLabels`, `useNpPhotoFolder`,
and `npResponsive`. Explicit imports keep their original names.

`localImages: true` resolves dimensions for hand-written local photo records.
The build reads `public/`; development updates the lookup when files change.
Remote images still need dimensions. A client manifest over 2,000 images
produces a warning. `usePhotoFolder` works independently of this option and
transfers only its requested folder.

## Lightbox options

| Key          | Type                                                                                                             | Default                              | Timing and meaning                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------- |
| `component`  | `Component`                                                                                                      | Built-in Lightbox in enabled recipes | Setup-time viewer choice.                                                                |
| `transition` | `'auto' \| 'flip' \| 'fade' \| 'none' \| { mode: 'auto' \| 'flip' \| 'fade' \| 'none'; autoThreshold?: number }` | `'auto'`, threshold `0.55`           | Reactive opening and closing animation.                                                  |
| `navigation` | `'slide' \| 'fade' \| 'crossfade'`                                                                               | `'slide'`                            | Reactive photo change mode.                                                              |
| `minZoom`    | `number`                                                                                                         | `1.5`                                | Setup-time lowest click zoom; positive finite number.                                    |
| `history`    | `boolean`                                                                                                        | `true`                               | Read on history operations; Back closes a viewer opened through its own entry.           |
| `deepLink`   | `boolean \| string`                                                                                              | `false`                              | `true` uses query key `photo`; a string names the key. Initial URL lookup is setup-time. |
| `tools`      | `LightboxTool[]`                                                                                                 | `[]`                                 | Reactive list: `download`, `share`, `fullscreen`.                                        |

`Photo` and `PhotoCarousel` default to no viewer. `PhotoAlbum` and `PhotoGroup`
default to an enabled viewer. Per-recipe `lightbox` accepts a boolean or these
options; set `component` inside the options to replace the viewer.
Use component objects in application component props. Nuxt module options are
serialized to runtime configuration, so component objects belong in app code.

## Merge and precedence

Built-in defaults are merged with app configuration, then the nearest group
or provider, then component overrides. A component's `provider` and
`validation` win over inherited values. Undefined values do not erase inherited
values. `lightbox` options merge by key; `tools` is replaced as a whole.
Per-label objects merge by key. A locale string replaces the inherited locale
and clears inherited label overrides. A label object retains the inherited
locale and overrides only defined keys.

A `PhotoGroup` owns the viewer. Descendant recipe lightbox options are ignored
with one development warning. Photo and image providers can still be
overridden per component. Global configuration does not enable a disabled-by-default recipe. Set the
recipe lightbox prop to `true` or an options object to enable its viewer.

## Image providers

Without Nuxt Image the native provider keeps `src` and optional `srcset`.
A native thumbnail uses `thumbSrc` when present and then omits the main
photo's `srcset`. With Nuxt Image, `image.provider`, `image.quality`,
`image.format`, `image.screens`, and `image.densities` are the source of image
settings. A `nuxtPhoto.provider` name overrides the Nuxt Image provider name.
IPX and ipxStatic default to WebP when no format is set. GIFs get no format
modifier; SVGs pass through without a srcset. Pre-encoded local paths are
decoded once before Nuxt Image.

The default Vue width ladder is `[128, 256, 384, 512, 640, 828, 1080, 1280,
1640, 1920, 2560]`. Nuxt uses sorted unique screens multiplied by densities,
with smaller default ladder widths below the first product. Vercel uses only
sorted unique screen widths, without density multiplication or a terminal
source-width candidate. Candidates never exceed source width. When allowed,
the exact source width is added if the ladder reaches or passes it. Duplicate
URLs become one candidate labeled with the larger width. A provider's
`srcset()` supplies fixed renditions instead.

Providers do not own `sizes`. Albums compute layout hints, carousels use the
measured track and slide size, and lightbox slides use fitted frame width.
`PhotoImage.sizes` and `PhotoAlbum.sizes` override their computed hints.
Explicit `placeholderSrc` wins over provider previews. IPX remote previews use
width `24` and quality `30`. Local folder records include build-time previews
up to 32 pixels wide when Sharp is resolvable; otherwise the build warns once
and omits those previews.

## Labels

Supported locales: `en`, `de`, `fr`, `es`, `it`, `nl`, `pt`, `ar`, and `he`.
Plain Vue detects `<html lang>` when no locale is configured; server rendering
falls back to `en`. Nuxt follows the reactive locale from `@nuxtjs/i18n` when
that module is installed; otherwise it uses `en`. Regional language codes
use their base language. Unsupported languages fall back to English.
An explicit locale string fixes the label locale. Nuxt includes English and
only configured or declared i18n locales in the build's label catalog.

Nuxt label overrides are strings. `goToSlide` and `viewPhoto` replace every
`{index}`; `slideStatus` replaces `{index}` and `{count}`. Index labels receive
one-based numbers. Vue's corresponding `PhotoLabels` keys are functions:
`(index: number) => string`, or `(index: number, count: number) => string` for
`slideStatus`. All other keys are strings.

| Label            | Default                      | Used for                         |
| ---------------- | ---------------------------- | -------------------------------- |
| `photoViewer`    | `Photo viewer`               | Lightbox accessible name         |
| `previous`       | `Previous`                   | Previous photo control           |
| `next`           | `Next`                       | Next photo control               |
| `zoom`           | `Zoom`                       | Zoom control                     |
| `fit`            | `Fit`                        | Reset zoom control               |
| `close`          | `Close`                      | Close control                    |
| `loadFailed`     | `Image could not be loaded.` | Image failure message            |
| `previousSlide`  | `Previous slide`             | Carousel previous control        |
| `nextSlide`      | `Next slide`                 | Carousel next control            |
| `pauseAutoplay`  | `Pause slideshow`            | Carousel pause button            |
| `playAutoplay`   | `Play slideshow`             | Carousel play button             |
| `download`       | `Download`                   | Download tool                    |
| `share`          | `Share`                      | Share tool                       |
| `fullscreen`     | `Full screen`                | Enter fullscreen                 |
| `exitFullscreen` | `Exit full screen`           | Exit fullscreen                  |
| `goToSlide`      | `Go to slide {index}`        | Carousel dot and thumbnail label |
| `viewPhoto`      | `View photo {index}`         | Photo trigger label              |
| `slideStatus`    | `Slide {index} of {count}`   | Polite slide announcement        |

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-photo'],
  nuxtPhoto: {
    labels: {
      close: 'Close viewer',
      slideStatus: 'Photo {index} of {count}',
    },
  },
})
```

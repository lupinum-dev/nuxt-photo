---
title: Photo API
description: A single photo, optionally with its own lightbox.
---

`<Photo>` renders one adapter-backed image with an optional caption and
lightbox. Its default interactive root is a native button; disabling the
lightbox renders a plain figure.

```vue
<template>
  <Photo :photo="hero" />
</template>

<script setup lang="ts">
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

const hero: PhotoItem = {
  id: 'hero',
  src: '/photos/desert.jpg',
  width: 1280,
  height: 800,
  alt: 'Desert at golden hour',
  caption: 'Desert Light',
}
</script>
```

## When to use

- A single editorial image on a landing page that should open full-screen on click.
- Inline images inside long-form content where a lightbox helps readability.
- Composing inside a `<PhotoGroup :photos="photos">` so several thumbnails share one explicit lightbox collection.

For a grid of many photos, prefer `<PhotoAlbum>`. For horizontal scrolling, prefer `<PhotoCarousel>`.

## Props

| Prop             | Type                       | Default                 | Description                                                                                                      |
| ---------------- | -------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `photo`          | `PhotoItem`                | -                       | **Required.** The photo to render.                                                                               |
| `lightbox`       | `boolean \| Component`     | `true`                  | Opens a solo lightbox. Pass `false` to disable it or a component to replace it. Ignored inside a `<PhotoGroup>`. |
| `lightboxIgnore` | `boolean`                  | `false`                 | When inside a `<PhotoGroup>`, make this thumbnail inert. The canonical group collection is unchanged.            |
| `imageAdapter`   | `ImageAdapter`             | provided/module default | Per-instance image adapter override.                                                                             |
| `transition`     | `LightboxTransitionOption` | `'auto'`                | Reactive transition configuration for a standalone lightbox.                                                     |
| `validation`     | `'throw' \| 'drop'`        | `'throw'`               | Throw for invalid data or render nothing until the photo becomes valid.                                          |
| `loading`        | `'lazy' \| 'eager'`        | `'lazy'`                | Passed through to the underlying `<img>`.                                                                        |
| `imgClass`       | `string`                   | -                       | Extra classes for the `<img>` element.                                                                           |
| `captionClass`   | `string`                   | -                       | Extra classes for the `<figcaption>`.                                                                            |

## Behavior

`<Photo>` has three modes depending on its context:

1. **Solo lightbox** - no `<PhotoGroup>` parent and `lightbox` is not `false`. Renders a native button trigger and mounts its own lightbox.
2. **Plain photo** - no parent and `lightbox` is `false`. Renders a non-interactive figure.
3. **Inside `<PhotoGroup>`** - contributes its thumbnail and optional slide
   renderer to the group's explicit collection. Clicking opens by stable photo
   ID. The `lightbox` prop is ignored inside a group; `lightboxIgnore` makes only
   this thumbnail inert.

## Slots

| Slot    | Slot props         | Description                                                           |
| ------- | ------------------ | --------------------------------------------------------------------- |
| `slide` | `{ photo, index }` | Replace the rendered slide inside the lightbox with your own content. |

Use the `slide` slot when the photo's lightbox view needs to be different from its thumbnail - adding a video player, a map, or a before/after comparison.

```vue
<Photo :photo="photo" lightbox>
  <template #slide="{ photo }">
    <div class="my-custom-slide">
      <h2>{{ photo.caption }}</h2>
      <img :src="photo.src" :alt="photo.alt" />
    </div>
  </template>
</Photo>
```

## Examples

### Standalone image (no lightbox)

```vue
<Photo :photo="hero" :lightbox="false" />
```

The figure renders; clicks do nothing. Use for decorative or hero images.

### Solo lightbox

```vue
<Photo :photo="hero" />
```

Clicking opens a lightbox with only this photo. Arrows are disabled because there is nothing to navigate to.

### Inside a `<PhotoGroup>`

```vue
<PhotoGroup :photos="photos">
  <div class="editorial-grid">
    <Photo v-for="p in photos" :key="p.id" :photo="p" />
  </div>
</PhotoGroup>
```

One lightbox serves every child; next/previous follow the order of the group's
explicit `photos` prop.

### Custom lightbox component

```vue
<script setup lang="ts">
import MyLightbox from './MyLightbox.vue'
</script>

<template>
  <Photo :photo="hero" :lightbox="MyLightbox" />
</template>
```

The custom component receives the lightbox context through the same provide/inject keys the built-in lightbox uses.

Nuxt Photo reports bundle size the modern way: by measuring what a consumer import adds to a production bundle.

We do **not** treat npm publish size or raw `dist/` output as the primary number. Those numbers are easy to quote and easy to misuse.

## What we measure

The repo ships a size harness behind `pnpm size` with two measurement modes:

- **`@lupinum/vue-photo`** uses tiny Vite fixtures, because the public surface includes Vue SFC exports and should be measured with a Vue-aware bundler.
- **`@lupinum/nuxt-photo`** uses tiny Nuxt fixtures and reports the emitted client-bundle delta versus a baseline app.

This keeps the measurement aligned with how each layer is actually consumed.

## Reference numbers in this repo revision

These numbers come from the in-repo harness. They move as the implementation changes. The thresholds live in the repo and are re-checked in CI.

| Surface               | Scenario                 | Current brotli   |
| --------------------- | ------------------------ | ---------------- |
| `@lupinum/vue-photo`  | `import { responsive }`  | `576 B`          |
| `@lupinum/vue-photo`  | `import { useLightbox }` | `659 B`          |
| `@lupinum/vue-photo`  | `import { PhotoImage }`  | `721 B`          |
| `@lupinum/vue-photo`  | `import * as NuxtPhoto`  | `31.4 kB`        |
| `@lupinum/nuxt-photo` | module enabled, no usage | `+1.29 kB` delta |
| `@lupinum/nuxt-photo` | one `PhotoImage` usage   | `+1.22 kB` delta |

## How to interpret them

- Prefer the number for the exact surface you plan to import.
- Treat focused Vue utility and primitive imports as the low-overhead path.
- Treat a full `@lupinum/vue-photo` namespace import as the rich path. Focused imports like `useLightbox` and `PhotoImage` stay much smaller.
- Treat `<PhotoCarousel>` separately from the lightbox and image primitives. It uses full Embla, so it is intentionally a richer import path.
- Treat Nuxt numbers as fixture deltas against the baseline app, not as standalone package size.

## Commands

```bash
pnpm size
pnpm size:vue
pnpm size:nuxt
pnpm size:analyze
```

- `pnpm size` runs the full report.
- `pnpm size:analyze` writes analyzer output to `test-results/size-analyze` for debugging regressions.

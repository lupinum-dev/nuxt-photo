title: PhotoCarousel API
description: Horizontal, swipeable carousel with thumbnails, autoplay, and optional lightbox.

`<PhotoCarousel>` is an [Embla](https://www.embla-carousel.com/)-powered horizontal gallery. One main rail, an optional thumbnail strip, and an optional lightbox on tap.

```vue
<PhotoCarousel :photos="photos" :lightbox="true" show-thumbnails />
```

::carousel-lab
::

## Props

| Prop              | Type                                      | Default                 | Description                                                             |
| ----------------- | ----------------------------------------- | ----------------------- | ----------------------------------------------------------------------- |
| `photos`          | `PhotoItem[]`                             | -                       | **Required.** The photos to show.                                       |
| `validation`      | `'throw' \| 'drop'`                       | `'throw'`               | Invalid photo policy.                                                   |
| `onInvalidPhotos` | `(event: InvalidPhotosEvent) => void`     | -                       | Receives validation issues when invalid photos are found.               |
| `imageAdapter`    | `ImageAdapter`                            | provided/module default | Per-instance image adapter override.                                    |
| `loop`            | `boolean`                                 | `false`                 | Wrap around at the ends.                                                |
| `dragFree`        | `boolean`                                 | `false`                 | Free dragging without snap points.                                      |
| `slidesToScroll`  | `number`                                  | `1`                     | Slides advanced per navigation.                                         |
| `options`         | `PhotoCarouselOptions`                    | -                       | Deprecated. Use the flat props above; flat props win when both are set. |
| `showArrows`      | `boolean`                                 | `true`                  | Render prev/next arrow buttons.                                         |
| `showThumbnails`  | `boolean`                                 | `true`                  | Render the thumbnail rail below the main rail.                          |
| `showCounter`     | `boolean`                                 | `true`                  | Render the `3 / 12` counter.                                            |
| `showDots`        | `boolean`                                 | `false`                 | Render dot indicators.                                                  |
| `autoplay`        | `boolean \| PhotoCarouselAutoplayOptions` | `false`                 | Enable autoplay with library-owned options.                             |
| `slideSize`       | `string`                                  | -                       | CSS `flex-basis` of each slide (e.g. `'100%'`, `'80%'`).                || `slideAspect`     | `string`                                  | -                       | CSS `aspect-ratio` per slide (e.g. `'16/9'`, `'1/1'`).                  |
| `gap`             | `string`                                  | -                       | CSS gap between slides.                                                 |
| `thumbSize`       | `string`                                  | -                       | Thumbnail width.                                                        |
| `lightbox`        | `boolean \| Component`                    | `true`                  | Enable a lightbox overlay on tap/click.                                 |
| `transition`      | `LightboxTransitionOption`                | `'auto'`                | Lightbox transition mode. Reactive.                                     |
| `slideClass`      | `string`                                  | -                       | Extra classes for each slide.                                           |
| `imgClass`        | `string`                                  | -                       | Extra classes for each `<img>`.                                         |
| `thumbClass`      | `string`                                  | -                       | Extra classes for each thumbnail.                                       |
| `captionClass`    | `string`                                  | -                       | Extra classes for the caption.                                          |
| `controlsClass`   | `string`                                  | -                       | Extra classes for the controls wrapper.                                 |

Carousel visual sizing props (`slideSize`, `slideAspect`, `gap`, `thumbSize`) are CSS length strings because they map straight to CSS custom properties. Album layout parameters are plain numbers in pixels because they feed the layout solver's math.

## Slots

| Slot       | Props                                                                              | Use it for                                      |
| ---------- | ---------------------------------------------------------------------------------- | ----------------------------------------------- |
| `slide`    | `{ photo, index, selected, open }`                                                 | Replace the main slide content.                 |
| `thumb`    | `{ photo, index, selected, goTo }`                                                 | Replace thumbnail button content.               |
| `caption`  | `{ photo, index, count }`                                                          | Replace the caption below the carousel.         |
| `controls` | `{ goToPrev, goToNext, canGoToPrev, canGoToNext, selectedIndex, snapCount, goTo }` | Replace the arrow controls as one custom block. |
| `prev`     | -                                                                                  | Replace only the previous-arrow label.          |
| `next`     | -                                                                                  | Replace only the next-arrow label.              |
| `dots`     | `{ snaps, selectedIndex, goTo }`                                                   | Replace dot indicators.                         |

Custom `slide` and `thumb` slots replace the default adapter-backed `<PhotoImage>` content. If the slot renders an image and should keep using the configured image adapter, render `<PhotoImage>` inside the slot.

## Carousel options

The public options are intentionally small and stable:

```ts
{
  loop: false,
  dragFree: false,
  slidesToScroll: 1,
}
```

Embla remains an internal implementation detail. Vendor plugins, private
engine state, and arbitrary Embla options are not part of Nuxt Photo's API.

## Examples

### Looping carousel with autoplay

```vue
<PhotoCarousel
  :photos="photos"
  :options="{ loop: true }"
  :autoplay="{
    delayMs: 4000,
    stopOnInteraction: false,
    stopOnMouseEnter: true,
  }"
/>
```

### Minimal - no chrome

```vue
<PhotoCarousel
  :photos="photos"
  :show-arrows="false"
  :show-thumbnails="false"
  :show-counter="false"
/>
```

Bare carousel, dragged by mouse/touch, no UI. Useful inside a design-heavy hero section.

### Multiple slides per view

```vue
<PhotoCarousel :photos="photos" slide-size="50%" gap="12px" />
```

Each slide takes 50% of the rail - users see two at a time with 12px between them.

### Custom slide aspect ratio

```vue
<PhotoCarousel :photos="photos" slide-aspect="21/9" />
```

Forces each slide to 21:9 regardless of the source aspect ratio.

### Carousel that opens a lightbox

```vue
<PhotoCarousel :photos="photos" :lightbox="true" />
```

Tap a slide - the lightbox opens at that photo. Swipe continues to work; the lightbox has its own navigation.

### Replace the built-in lightbox for this carousel

```vue
<script setup lang="ts">
import MyLightbox from '~/components/MyLightbox.vue'
</script>

<template>
  <PhotoCarousel :photos="photos" :lightbox="MyLightbox" />
</template>
```

Use this when the carousel should keep its own track, thumbnails, and controls but open a different lightbox UI.

### Autoplay interaction behavior

```vue
<!-- prop form -->
<PhotoCarousel :photos="photos" :autoplay="{ delayMs: 3000, stopOnInteraction: true }" />
```

title: PhotoAlbum API
description: A grid of photos in rows, columns, or masonry, with a lightbox baked in.
---

`<PhotoAlbum>` is the workhorse. Give it a list of photos and a layout - rows, columns, or masonry - and you get a responsive grid with an integrated lightbox, gestures, and FLIP transitions.

```vue
<PhotoAlbum :photos="photos" layout="rows" />
```

::album-layout-lab
::

## Layouts

Three layout algorithms; each responds to container width.

### Rows (justified)

```vue
<PhotoAlbum :photos="photos" :layout="{ type: 'rows', targetRowHeight: 240 }" />
```

Images stretch horizontally to fill each row at a consistent height - the "Flickr look". Best for mixed aspect ratios.

Options:

- `targetRowHeight` - pixel height each row tries to hit. Accepts a responsive parameter. Default `300`.

### Columns

```vue
<PhotoAlbum :photos="photos" :layout="{ type: 'columns', columns: 3 }" />
```

Fixed-column grid. Every photo in a column is the same width; heights vary. Best when every image looks similar.

Options:

- `columns` - number of columns. Accepts a responsive parameter. Default `3`.

### Masonry

```vue
<PhotoAlbum :photos="photos" :layout="{ type: 'masonry', columns: 4 }" />
```

Fixed-column Pinterest-style layout - photos flow into the shortest column next. Best when visual density matters more than reading order.

Options:

- `columns` - number of columns. Accepts a responsive parameter. Default `3`.

::idea
You can pass `layout` as a string (`"rows"`, `"columns"`, `"masonry"`) to use the default options for that algorithm, or as an object for full control.
::

## Props

| Prop                    | Type                                              | Default                  | Description                                                                                                                           |
| ----------------------- | ------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `photos`                | `PhotoItem[]`                                     | -                        | **Required.** The photos to lay out.                                                                                                  |
| `validation`            | `'throw' \| 'drop'`                               | `'throw'`                | Invalid photo policy.                                                                                                                 |
| `onInvalidPhotos`       | `(event: InvalidPhotosEvent) => void`             | -                        | Receives validation issues when invalid photos are found.                                                                             |
| `layout`                | `'rows' \| 'columns' \| 'masonry' \| AlbumLayout` | `'rows'`                 | Layout algorithm and options.                                                                                                         |
| `spacing`               | `ResponsiveParameter<number>`                     | `8`                      | Gap between images in px.                                                                                                             |
| `padding`               | `ResponsiveParameter<number>`                     | `0`                      | Padding around each image in px.                                                                                                      |
| `defaultContainerWidth` | `number`                                          | -                        | Assumed container width for deterministic SSR layout.                                                                                 |
| `breakpoints`           | `readonly number[]`                               | auto from `responsive()` | Snap client-observed width to the largest breakpoint ≤ actual.                                                                        |
| `sizes`                 | `string \| ResponsivePhotoSizes`                  | -                        | `<img sizes>` for rows layout. A plain string passes through verbatim; the structured form derives a layout-exact `calc()` per photo. |
| `imageAdapter`          | `ImageAdapter`                                    | provided/module default  | Per-instance image adapter override.                                                                                                  |
| `lightbox`              | `boolean \| Component`                            | `true`                   | Enable the built-in lightbox, disable it, or pass a custom one. Read once on mount; remount to change it.                             |
| `transition`            | `LightboxTransitionOption`                        | `'auto'`                 | FLIP/fade mode for open/close animation. Reactive.                                                                                    |
| `itemClass`             | `string`                                          | -                        | Extra classes for each item wrapper.                                                                                                  |
| `imgClass`              | `string`                                          | -                        | Extra classes for each `<img>`.                                                                                                       |

Responsive layout props (`layout` options, `spacing`, `padding`, and `breakpoints`) are reactive. If your app swaps breakpoint sets or layout parameters at runtime, the album recomputes against the current container width.

## Exposed controller

The album exposes a small lightbox controller through a template ref:

```vue
<script setup lang="ts">
import { ref } from 'vue'

const album = ref()
</script>

<template>
  <button @click="album.open(0)">Open gallery</button>
  <PhotoAlbum ref="album" :photos="photos" />
</template>
```

| Member     | Type                          | Description                                |
| ---------- | ----------------------------- | ------------------------------------------ |
| `open`     | `(index?: number) => Promise` | Open the lightbox at a photo index.        |
| `openById` | `(id: string) => Promise`     | Open the lightbox for a photo id.          |
| `close`    | `() => Promise`               | Close the lightbox.                        |
| `isOpen`   | `boolean`                     | Whether the lightbox is currently visible. |

When the album sits inside a `<PhotoGroup>`, these calls delegate to the group's shared lightbox.

## Slots

| Slot        | Slot props                                | Description                                                                     |
| ----------- | ----------------------------------------- | ------------------------------------------------------------------------------- |
| `thumbnail` | `{ photo, index, width, height, hidden }` | Replace the rendered thumbnail. Useful for overlays, captions-on-hover, badges. |

The `thumbnail` slot receives a `hidden` boolean that flips to `true` during the FLIP transition - useful if you stack an overlay over the image and need to hide it while the transition animates.

## Examples

### Responsive columns layout

```vue [code]
<template>
  <PhotoAlbum
    :photos="photos"
    :layout="{
      type: 'columns',
      columns: responsive({ 0: 2, 640: 3, 1024: 4 }),
    }"
    :spacing="responsive({ 0: 4, 640: 8, 1024: 12 })"
  />
</template>
```

In Nuxt apps, `responsive()` is auto-imported. In plain Vue apps, import it from
`@lupinum/vue-photo`.

### Masonry layout

```vue [code]
<template>
  <PhotoAlbum :photos="photos" :layout="{ type: 'masonry', columns: 3 }" :spacing="8" />
</template>
```

### SSR-friendly rows

```vue
<PhotoAlbum
  :photos="photos"
  layout="rows"
  :default-container-width="1200"
  :breakpoints="[375, 768, 1200]"
/>
```

The rows layout runs on the server at 1200px. After mount, the client snaps measured widths to the largest matching breakpoint.

- [SSR and CLS](/docs/concepts/ssr-and-layout-stability)

### Disable the lightbox

```vue
<PhotoAlbum :photos="photos" :lightbox="false" />
```

Useful when the album sits inside another pattern (e.g. a carousel of albums, or custom routing where clicks go to a detail page).

A parent `<PhotoGroup :lightbox="false">` also renders child albums as plain
layouts, even if the album itself does not set `:lightbox="false"`.

### Replace the built-in lightbox for this album

```vue
<script setup lang="ts">
import MyLightbox from '~/components/MyLightbox.vue'
</script>

<template>
  <PhotoAlbum :photos="photos" :lightbox="MyLightbox" />
</template>
```

Use this when the album should keep the normal trigger and transition behavior but render a different lightbox UI.

- [Customize the built-in lightbox](/docs/guides/customize-the-lightbox)

### Custom thumbnail overlay

```vue
<PhotoAlbum :photos="photos" layout="rows">
  <template #thumbnail="{ photo, hidden }">
    <div class="thumb" :style="{ opacity: hidden ? 0 : 1 }">
      <img :src="photo.thumbSrc ?? photo.src" :alt="photo.alt" />
      <span class="badge">{{ photo.meta?.tag }}</span>
    </div>
  </template>
</PhotoAlbum>
```

The `thumbnail` slot replaces the default adapter-backed thumbnail renderer. If your custom thumbnail should still use the configured image adapter, render `<PhotoImage>` inside the slot instead of a raw `<img>`.

### Feeding CMS data

```ts
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

type ContentfulAsset = {
  sys: { id: string }
  fields: {
    title?: string
    file: {
      url: string
      details: { image: { width: number; height: number } }
    }
  }
}

const photos = computed<PhotoItem[]>(() =>
  contentfulAssets.value.map((item) => ({
    id: item.sys.id,
    src: item.fields.file.url,
    width: item.fields.file.details.image.width,
    height: item.fields.file.details.image.height,
    alt: item.fields.title,
  })),
)
```

```vue
<PhotoAlbum :photos="photos" />
```

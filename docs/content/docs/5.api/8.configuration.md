---
title: Nuxt configuration
description: Build-time module settings in nuxt.config and UI defaults in app.config.
---

Nuxt Photo has one owner for each kind of configuration:

- `nuxt.config.ts` controls build-time integration: components, auto-imports,
  CSS, and the image adapter.
- `app.config.ts` controls serializable UI defaults: labels and minimum zoom.
- Recipe props control one component instance.

## Module options

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@lupinum/nuxt-photo'],
  nuxtPhoto: {
    autoImports: true,
    components: { prefix: '', primitives: false },
    css: 'all',
    image: { provider: 'auto' },
  },
})
```

These are the only module option roots.

### `autoImports`

- **Type:** `boolean | { prefix?: string }`
- **Default:** `true`

Auto-imports `useLightbox`, `provideLightbox`, `usePhotoLabels`,
`providePhotoLabels`, and `responsive`.

```ts
nuxtPhoto: {
  autoImports: false
}
```

With `{ prefix: 'Np' }`, composables and helpers receive the same prefixing
scheme as other Nuxt auto-imports.

### `components`

- **Type:** `boolean | { prefix?: string; primitives?: boolean }`
- **Default:** `{ prefix: '', primitives: false }`

Registers the five recipes: `<Photo>`, `<PhotoAlbum>`, `<PhotoGroup>`,
`<PhotoCarousel>`, and `<Lightbox>`.

```ts
nuxtPhoto: {
  components: { prefix: 'Np', primitives: true }
}
```

Set `primitives: true` only for custom interfaces that use components such as
`<LightboxRoot>`, `<LightboxViewport>`, and `<PhotoTrigger>` directly.

### `css`

- **Type:** `'none' | 'structure' | 'all'`
- **Default:** `'all'`

| Value         | Loaded content            | Use it when                                 |
| ------------- | ------------------------- | ------------------------------------------- |
| `'all'`       | Structure + default theme | You want a complete installation.           |
| `'structure'` | Layout and geometry only  | You will provide the complete visual theme. |
| `'none'`      | No library CSS            | You will replace structure and theme CSS.   |

The structure rules are required for the library's layout geometry. Use
`'none'` only when your stylesheet replaces them.

### `image`

- **Type:** `false | { provider?: 'auto' | 'nuxt-image' | 'native'; thumb?: object; slide?: object }`
- **Default:** `{ provider: 'auto' }`

| Value          | Behavior                                                                      |
| -------------- | ----------------------------------------------------------------------------- |
| `'auto'`       | Uses `@nuxt/image` when installed; otherwise silently uses native images.     |
| `'nuxt-image'` | Requires `@nuxt/image` and reports an error when the module is absent.        |
| `'native'`     | Uses browser image sources without a generated adapter.                       |
| `false`        | Registers no module adapter, so the app can provide `ImageAdapterKey` itself. |

Thumbnail and slide settings belong only here. Nuxt Photo warns when you supply
adapter-specific settings in a mode where they cannot take effect.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/image', '@lupinum/nuxt-photo'],
  nuxtPhoto: {
    image: {
      provider: 'nuxt-image',
      thumb: {
        sizes: 'sm:100vw md:50vw lg:400px',
        quality: 80,
      },
      slide: {
        widths: [640, 960, 1240, 1600, 2000],
        maxWidth: 1240,
        maxDensity: 1.5,
        sizes: 'min(1240px, calc(100vw - 72px))',
        quality: 85,
      },
    },
  },
})
```

Configure the upstream Nuxt Image provider in Nuxt's own `image` block.

## AppConfig defaults

UI defaults are typed under `nuxtPhoto` in `app.config.ts`.

```ts [app.config.ts]
export default defineAppConfig({
  nuxtPhoto: {
    lightbox: {
      minZoom: 1.2,
    },
    labels: {
      close: 'Schließen',
      counter: 'Bild {index} von {count}',
      goToSlide: 'Zu Bild {index}',
      viewPhoto: 'Bild {index} öffnen',
    },
  },
})
```

AppConfig labels are serializable strings. Indexed labels support `{index}`;
the counter also supports `{count}`. All visible text and accessibility labels
resolve through this source.

For a locale that changes while the app is running, provide Vue labels from an
app plugin:

```ts [plugins/photo-labels.ts]
export default defineNuxtPlugin(() => {
  const locale = useState<'en' | 'de'>('locale')

  providePhotoLabels(() => ({
    close: locale.value === 'de' ? 'Schließen' : 'Close',
    counter: (index, count) => `${index} / ${count}`,
  }))
})
```

Vue label functions are intentionally more flexible than serializable
AppConfig strings. Plugin-provided labels take precedence over AppConfig
defaults.

## Instance overrides

Set `lightbox`, `transition`, `imageAdapter`, and other recipe behavior on the
recipe component that owns it. These props are reactive; removing an override
restores the inherited or built-in default.

[Review the `PhotoItem` model](/docs/concepts/photo-model)

---
title: Integrate a custom image service
description: Resolve thumbnail and slide sources through one deterministic adapter.
---

An image adapter receives a photo and either the `thumb` or `slide` context. It
returns the attributes for the final `img` element.

```ts [app/utils/photo-adapter.ts]
import type { ImageAdapter, PhotoItem } from '@nuxt-photo/nuxt/app'

const baseUrl = 'https://images.example.com/transform'

function source(photo: PhotoItem, width: number) {
  return `${baseUrl}/${photo.id}?width=${width}&format=webp`
}

export const photoAdapter: ImageAdapter = (photo, context) => {
  const widths = context === 'thumb' ? [480, 960] : [960, 1440, 1920]

  return {
    src: source(photo, widths.at(-1)!),
    srcset: widths.map((width) => `${source(photo, width)} ${width}w`).join(', '),
    sizes: context === 'thumb' ? '(min-width: 960px) 33vw, 100vw' : '100vw',
    width: photo.width,
    height: photo.height,
  }
}
```

Always return `src`. Return dimensions when the final image should keep
intrinsic width and height attributes. Keep the adapter deterministic so SSR
and hydration produce the same URLs; resolve time-sensitive signatures before
rendering rather than calling `Date.now()` in the adapter.

## Provide it to the app

Disable the module-provided adapter, then provide the custom one in a universal
Nuxt plugin.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    image: false,
  },
})
```

```ts [app/plugins/photo-adapter.ts]
import { ImageAdapterKey } from '@nuxt-photo/nuxt/app'
import { photoAdapter } from '~/utils/photo-adapter'

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.provide(ImageAdapterKey, photoAdapter)
})
```

`image: false` skips Nuxt Photo's injected adapter. `PhotoImage` still has a
native fallback, so a missing custom provider renders the original source
rather than disabling images.

## Override one collection

An `image-adapter` prop takes precedence over the injected adapter. Use it when
one collection comes from a different image service.

```vue [app/pages/gallery.vue]
<script setup lang="ts">
import { photoAdapter } from '~/utils/photo-adapter'
</script>

<template>
  <PhotoAlbum :photos="photos" :image-adapter="photoAdapter" />
</template>
```

Test the adapter as a pure function for both contexts and assert the exact
`src`, `srcset`, `sizes`, `width`, and `height` values. The [image pipeline]($docs/concepts/image-pipeline)
explains adapter precedence and the native and Nuxt Image modes.

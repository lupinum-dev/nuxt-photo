---
title: Customize the recipe lightbox
description: Replace captions, actions, counters, or slides while keeping the built-in runtime.
---

Wrap the recipe `Lightbox` when its focus management, gestures, zoom, and
transitions are correct but the visible controls need different markup.

```vue [app/components/PortfolioLightbox.vue]
<script setup lang="ts">
import { Lightbox } from '@nuxt-photo/nuxt/app'
</script>

<template>
  <Lightbox>
    <template #counter="{ activeIndex, count }">
      <span>{{ activeIndex + 1 }} / {{ count }}</span>
    </template>

    <template #caption="{ photo }">
      <div v-if="photo">
        <h2 v-if="photo.caption">{{ photo.caption }}</h2>
        <p v-if="photo.description">{{ photo.description }}</p>
      </div>
    </template>

    <template
      #actions="{ prev, next, close, toggleZoom, isZoomedIn, zoomAllowed, controlsDisabled }"
    >
      <button type="button" :disabled="controlsDisabled" @click="prev">Previous</button>
      <button type="button" :disabled="controlsDisabled" @click="next">Next</button>
      <button type="button" :disabled="controlsDisabled || !zoomAllowed" @click="toggleZoom">
        {{ isZoomedIn ? 'Fit image' : 'Zoom image' }}
      </button>
      <button type="button" :disabled="controlsDisabled" @click="close">Close</button>
    </template>
  </Lightbox>
</template>
```

Lightbox navigation loops, so previous and next controls do not need to disable
at the ends of the collection.

Pass the wrapper through the recipe component's `lightbox` prop:

```vue [app/pages/portfolio.vue]
<script setup lang="ts">
import PortfolioLightbox from '~/components/PortfolioLightbox.vue'
</script>

<template>
  <PhotoAlbum :photos="photos" :lightbox="PortfolioLightbox" />
</template>
```

`lightbox` is selected during provider setup. Remount the album, group, or
carousel when the component choice changes at runtime. Build a [primitive
lightbox]($docs/customization/custom-lightbox) only when the overlay, viewport,
or control hierarchy itself must change.

---
title: Build a custom lightbox
description: Compose the primitive viewer when the recipe markup is no longer enough.
---

The primitive layer keeps Nuxt Photo state, transitions, gestures, pan, and
zoom while giving you control over the dialog structure. A custom composition
must provide its own accessible name, controls, and layout CSS.

## Create the viewer component

```vue [app/components/PrimitiveLightbox.vue]
<script setup lang="ts">
import {
  LightboxCaption,
  LightboxControls,
  LightboxOverlay,
  LightboxRoot,
  LightboxSlide,
  LightboxViewport,
} from '@nuxt-photo/nuxt/app'
</script>

<template>
  <LightboxRoot class="np-lightbox" role="dialog" aria-modal="true" aria-label="Photo viewer">
    <LightboxOverlay class="np-lightbox__backdrop" />

    <div class="np-lightbox__ui">
      <LightboxControls
        v-slot="{ activeIndex, count, prev, next, close, controlsDisabled }"
        class="np-lightbox__controls"
      >
        <div class="np-lightbox__topbar">
          <span class="np-lightbox__counter">{{ activeIndex + 1 }} / {{ count }}</span>
          <div class="np-lightbox__actions">
            <button
              class="np-lightbox__btn np-lightbox__btn--prev"
              type="button"
              aria-label="Previous photo"
              :disabled="controlsDisabled"
              @click="prev"
            >
              &larr;
            </button>
            <button
              class="np-lightbox__btn np-lightbox__btn--next"
              type="button"
              aria-label="Next photo"
              :disabled="controlsDisabled"
              @click="next"
            >
              &rarr;
            </button>
            <button
              class="np-lightbox__btn np-lightbox__btn--close"
              type="button"
              aria-label="Close photo viewer"
              @click="close"
            >
              &times;
            </button>
          </div>
        </div>
      </LightboxControls>

      <div class="np-lightbox__stage">
        <LightboxViewport
          v-slot="{ photos, viewportRef, imageLoadFailed }"
          class="np-lightbox__media"
        >
          <div :ref="viewportRef" class="np-lightbox__viewport">
            <div class="np-lightbox__container">
              <LightboxSlide
                v-for="(photo, index) in photos"
                :key="photo.id"
                :photo="photo"
                :index="index"
                class="np-lightbox__slide"
              />
            </div>
          </div>
          <p v-if="imageLoadFailed" class="np-lightbox__fallback" role="status">
            Image could not be loaded.
          </p>
        </LightboxViewport>

        <LightboxCaption v-slot="{ photo }" class="np-lightbox__caption">
          <p v-if="photo?.caption">{{ photo.caption }}</p>
        </LightboxCaption>
      </div>
    </div>
  </LightboxRoot>
</template>
```

The `np-lightbox` classes reuse Nuxt Photo's structural CSS, which the module
loads by default and also includes with `css: 'all'`. Replace those classes
only when you provide equivalent layout rules. `viewportRef` belongs on the
Embla viewport element, whose direct child is the slide container. The
[primitive reference]($docs/components/lightbox-primitives) documents the slot
contracts and required nesting.

## Use it with a recipe

```vue [app/pages/portfolio.vue]
<script setup lang="ts">
import PrimitiveLightbox from '~/components/PrimitiveLightbox.vue'
</script>

<template>
  <PhotoAlbum :photos="photos" :lightbox="PrimitiveLightbox" />
</template>
```

`LightboxRoot` teleports to `body`, traps focus, restores focus after closing,
and makes other body children inert while open. Keep `role="dialog"`,
`aria-modal="true"`, and an accessible name on the custom root. Test Escape,
arrow keys, keyboard focus, touch dismissal, zoom, and reduced motion before
replacing the recipe viewer in production.

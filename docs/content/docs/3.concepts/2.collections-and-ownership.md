---
title: Collections and ownership
description: One explicit collection owns photo identity and lightbox navigation order.
---

Every lightbox provider owns one ordered collection. Visual descendants may register thumbnail elements and custom slide renderers, but they do not construct another collection.

::collection-ownership-lab
::

## Mental model

```text
PhotoGroup.photos             Canonical identity and navigation order
        |
        +-- PhotoAlbum        Registers thumbnail capabilities
        +-- Photo             Registers one trigger capability
        +-- custom trigger    Registers one trigger capability
        |
        +-- lightbox runtime  Reads the canonical collection
```

## Why DOM order is not canonical

DOM order can change when a responsive layout moves sections, a keyed list reorders, or a component mounts conditionally. Deriving navigation from mount order would make next and previous behavior depend on rendering details.

`PhotoGroup.photos` keeps the order explicit:

```vue
<PhotoGroup :photos="[...landscapes, ...portraits]">
  <PhotoAlbum :photos="landscapes" />
  <PhotoAlbum :photos="portraits" />
</PhotoGroup>
```

## Invariants

- Every descendant photo ID must exist in the group collection.
- IDs remain stable and unique.
- Two descendants cannot register competing custom slide renderers for one ID.
- Only one lightbox owns modal focus and page isolation at a time.

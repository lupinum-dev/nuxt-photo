---
title: Create a custom thumbnail layout
description: Render thumbnails in any layout you build yourself - a grid, a hexagon grid, a list - and keep the built-in lightbox, keyboard access, and opening animation with LightboxProvider, PhotoTrigger, and PhotoImage.
---

When rows, columns, and masonry do not fit your design, lay out the thumbnails
yourself. Three components keep the lightbox working:

- `LightboxProvider` holds the photos and the lightbox state.
- `PhotoTrigger` makes one thumbnail open its photo, with keyboard support and
  the opening animation.
- `Lightbox` is the built-in viewer.

```vue [app/components/FeatureGrid.vue]
<script setup lang="ts">
import { Lightbox, LightboxProvider, PhotoImage, PhotoTrigger } from '@lupinum/nuxt-photo/app'
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

defineProps<{ photos: PhotoItem[] }>()
</script>

<template>
  <LightboxProvider :photos="photos">
    <div class="feature-grid">
      <PhotoTrigger
        v-for="(photo, index) in photos"
        :key="photo.id"
        v-slot="{ hidden }"
        :photo="photo"
        :index="index"
        class="feature-grid__item"
      >
        <PhotoImage :photo="photo" context="thumb" :style="{ opacity: hidden ? 0 : 1 }" />
      </PhotoTrigger>
    </div>
    <Lightbox />
  </LightboxProvider>
</template>

<style scoped>
.feature-grid {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 8px;
}

.feature-grid__item:first-child {
  grid-row: span 2;
}

.feature-grid__item :deep(img) {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
</style>
```

## Rules

- `index` is the photo's position in the provider's `photos`. It sets which
  photo opens and the lightbox order.
- `hidden` is `true` while the opening or closing animation stands in for this
  thumbnail. Hide the thumbnail then, or the photo appears twice.
- Render `PhotoImage` for the thumbnail, not a plain `<img>`, so it uses your
  image delivery.
- `PhotoTrigger` renders a button: click, `Enter`, and `Space` open the photo.

## Open a photo from a button in the layout

A component inside the provider can control the lightbox with `useLightbox()`:

```vue [app/components/OpenFirstButton.vue]
<script setup lang="ts">
import { useLightbox } from '@lupinum/nuxt-photo/app'

const lightbox = useLightbox()
</script>

<template>
  <button type="button" @click="lightbox.open(0)">View all photos</button>
</template>
```

Render it inside `LightboxProvider`. `useLightbox()` only finds a provider in a
parent component, not in the same component.

## When PhotoGroup is the better choice

When your layout is made of `PhotoAlbum` and `Photo` components, wrap them in
[`PhotoGroup`](/docs/guides/share-one-lightbox) instead. Use
`LightboxProvider` when you render every thumbnail yourself.

## Check the result

Tab to a thumbnail and press `Enter`: the lightbox opens from that thumbnail.
Press `Escape`: focus returns to the thumbnail of the photo you were viewing.

---

`PhotoCarousel` shows one photo at a time with arrows, a counter, and a
thumbnail rail. Swipe or drag to browse. The lightbox is off until you turn it
on.

::example{name="product-gallery"}
::

## Add a carousel

```vue [app/pages/print.vue]
<script setup lang="ts">
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

const photos: PhotoItem[] = [
  { id: 'canyon', src: '/photos/canyon.jpg', width: 1280, height: 853, alt: 'Moss canyon' },
  { id: 'ridge', src: '/photos/ridge.jpg', width: 1280, height: 853, alt: 'Green ridge' },
]
</script>

<template>
  <PhotoCarousel :photos="photos" slide-aspect="3/2" :lightbox="true" />
</template>
```

`:lightbox="true"` makes a selected slide open in the lightbox. `lightbox` is
read at mount; change the component `key` to turn it on or off later.

## Choose the controls

| Prop             | Default | Effect                                     |
| ---------------- | ------- | ------------------------------------------ |
| `showArrows`     | `true`  | Previous and next buttons.                 |
| `showThumbnails` | `true`  | The thumbnail rail.                        |
| `showCounter`    | `true`  | The "2 / 6" counter.                       |
| `showDots`       | `false` | One dot per slide.                         |
| `loop`           | `false` | Continue from the last slide to the first. |

```vue
<PhotoCarousel :photos="photos" loop show-dots :show-thumbnails="false" />
```

## Show part of the next slide

```vue
<PhotoCarousel :photos="photos" slide-size="70%" gap="12px" />
```

`slideSize` sets the width of each slide. Each arrow press still moves one
slide. `thumbSize` sets the thumbnail height; the width follows each photo.

## Play automatically

```vue
<PhotoCarousel
  :photos="photos"
  loop
  :autoplay="{ delayMs: 5000, stopOnInteraction: true, stopOnMouseEnter: true }"
/>
```

`autoplay: true` uses 4000 ms, stops after the first interaction, and keeps
playing when the pointer is over the carousel. Write out all three fields when
the behavior matters, so a later reader sees it.

While autoplay runs, a pause button sits in the top corner, first in the tab
order, and the counter stops announcing each slide to screen readers. Autoplay
does not run for readers who prefer reduced motion, and starts when that
preference is removed.

## Support right-to-left pages

The carousel reads computed CSS direction from its root at mount. Set `dir` on
an ancestor, or use CSS `direction` on the gallery root:

```vue
<div :dir="locale.dir">
  <PhotoCarousel :key="locale.dir" :photos="photos" />
</div>
```

The key remounts the inline track when direction changes. Lightboxes read the
gallery root direction again each time they open.

## Build your own controls

The `controls` slot replaces the arrows and counter and gives you the actions:

```vue
<PhotoCarousel :photos="photos">
  <template #controls="{ goToPrev, goToNext, canGoToPrev, canGoToNext, selectedIndex, snapCount }">
    <div class="carousel-nav">
      <button type="button" :disabled="!canGoToPrev" @click="goToPrev">Previous</button>
      <span>{{ selectedIndex + 1 }} of {{ snapCount }}</span>
      <button type="button" :disabled="!canGoToNext" @click="goToNext">Next</button>
    </div>
  </template>
</PhotoCarousel>
```

Use native buttons and keep their visible focus. The
[PhotoCarousel reference](/docs/reference/photo-carousel#slots) lists every
slot. Nuxt Photo does not expose other Embla options or plugins.

## Check the result

Drag, use the arrows, and select a thumbnail: the counter and thumbnail follow.
With `:lightbox="true"`, selecting the large photo opens the lightbox, and
`Escape` returns focus to the carousel.

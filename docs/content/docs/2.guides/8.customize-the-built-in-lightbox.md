---
title: Customize the lightbox
description: Change the built-in lightbox without rebuilding it - download, share and full screen buttons, custom caption, counter, tool and action buttons with slots, slide overlays, fade or crossfade navigation, one lightbox for the whole app, and when to use lower-level components instead.
---

Keep the built-in lightbox and replace only the parts you want. It still
handles focus, keyboard, gestures, zoom, and the opening animation.

By default it already shows each photo's `caption` and `description` under the
photo, and a counter and buttons above it. Set those fields on your photos; you
need a slot only to change how they look.

## Choose how far to go

| You want to change                              | Use                                                                        |
| ----------------------------------------------- | -------------------------------------------------------------------------- |
| Colors, mat, buttons                            | CSS variables: [Style and theme](/docs/guides/style-and-theme)             |
| How photos change: slide, fade, crossfade       | The `lightbox.navigation` option                                           |
| Caption, counter, action buttons, slide content | `Lightbox` slots, on this page                                             |
| Your own thumbnail layout                       | [A custom thumbnail layout](/docs/guides/create-a-custom-thumbnail-layout) |
| The whole lightbox markup                       | [Lightbox from primitives](/docs/guides/build-a-lightbox-from-primitives)  |

Stay at the first level that works. A custom caption does not need a custom
lightbox, and a custom thumbnail layout does not need a custom viewer.

## Fade or crossfade between photos

```vue
<PhotoAlbum :photos="photos" :lightbox="{ navigation: 'crossfade' }" />
```

`slide` (default) moves photos on a strip, `fade` fades the current photo out
and the next in, and `crossfade` fades the next photo in over the current one.
Swiping works in every mode. The `lightbox` option is the same on `Photo`,
`PhotoAlbum`, `PhotoGroup`, and `PhotoCarousel`.

## Add download, share and full screen buttons

```vue
<PhotoAlbum :photos="photos" :lightbox="{ tools: ['download', 'share', 'fullscreen'] }" />
```

The buttons appear before the zoom button, in the order you list them:

| Tool         | What it does                                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `download`   | Downloads `photo.src`. For an image on another domain the browser ignores the download request, so the photo opens in a new tab.     |
| `share`      | Opens the system share sheet with the photo's `alt` or `caption` and the page URL; with `deepLink`, the URL opens this photo.      |
| `fullscreen` | Shows the lightbox in full screen, and leaves it on a second press.                                                                |

`share` and `fullscreen` are not rendered when the browser does not support
them; iPhone Safari has no full screen for elements. Their labels are in
every bundled language.

To add your own button next to them, use the `tools` slot. It keeps the
built-in tools, zoom and close:

```vue [app/components/LikeLightbox.vue]
<script setup lang="ts">
import { Lightbox } from '@lupinum/nuxt-photo/app'

defineEmits<{ like: [id: string] }>()
</script>

<template>
  <Lightbox>
    <template #tools="{ photo }">
      <button type="button" class="np-lightbox__btn" aria-label="Like" @click="$emit('like', photo.id)">
        ♥
      </button>
    </template>
  </Lightbox>
</template>
```

## Replace the caption and counter

Wrap `Lightbox` in your own component, fill the slots you need, and pass the
component to the `lightbox` prop:

::example{name="caption-gallery" also="caption-lightbox" code="open"}
::

Slot props:

| Slot      | Props                                                                                              |
| --------- | -------------------------------------------------------------------------------------------------- |
| `counter` | `{ activeIndex, count }`                                                                           |
| `caption` | `{ photo, index }`                                                                                 |
| `tools`   | `{ photo, index }`                                                                                 |
| `actions` | `{ activePhoto, activeIndex, count, prev, next, close, toggleZoom, isZoomedIn, zoomAllowed, controlsDisabled }` |
| `slide`   | `{ photo, index, width, height }`                                                                  |

## Replace the action buttons

The `actions` slot replaces all buttons above the photo: tools, zoom and close.

```vue [app/components/AppLightbox.vue]
<script setup lang="ts">
import { Lightbox } from '@lupinum/nuxt-photo/app'
</script>

<template>
  <Lightbox>
    <template #actions="{ toggleZoom, isZoomedIn, zoomAllowed, close, controlsDisabled }">
      <button
        v-if="zoomAllowed"
        type="button"
        class="np-lightbox__btn"
        :disabled="controlsDisabled"
        :aria-label="isZoomedIn ? 'Zoom out' : 'Zoom in'"
        @click="toggleZoom"
      >
        {{ isZoomedIn ? '−' : '+' }}
      </button>
      <button
        type="button"
        class="np-lightbox__btn"
        :disabled="controlsDisabled"
        aria-label="Close"
        @click="close"
      >
        ×
      </button>
    </template>
  </Lightbox>
</template>
```

Use native buttons with an accessible name, and keep `disabled` and the visible
focus style.

## Add an overlay to each slide

The `slide` slot replaces the image area of each slide. Render `PhotoImage` to
keep your image delivery:

```vue [app/components/CreditLightbox.vue]
<script setup lang="ts">
import { Lightbox, PhotoImage } from '@lupinum/nuxt-photo/app'
</script>

<template>
  <Lightbox>
    <template #slide="{ photo }">
      <figure class="credit-slide">
        <PhotoImage :photo="photo" context="slide" class="credit-slide__image" />
        <figcaption v-if="photo.meta?.photographer" class="credit-slide__credit">
          Photo: {{ photo.meta.photographer }}
        </figcaption>
      </figure>
    </template>
  </Lightbox>
</template>

<style scoped>
.credit-slide {
  position: relative;
  width: 100%;
  height: 100%;
  margin: 0;
}

.credit-slide__image {
  width: 100%;
  height: 100%;
  object-fit: contain;
}

.credit-slide__credit {
  position: absolute;
  right: 12px;
  bottom: 12px;
  padding: 4px 8px;
  border-radius: 4px;
  background: rgb(0 0 0 / 0.6);
  color: #fff;
  font-size: 12px;
}
</style>
```

## Use one custom lightbox everywhere

Pass the component per gallery:

```vue
<PhotoAlbum :photos="photos" :lightbox="{ component: CaptionLightbox }" />
<PhotoGroup :photos="photos" :lightbox="{ component: CaptionLightbox }">...</PhotoGroup>
<PhotoCarousel :photos="photos" :lightbox="{ component: CaptionLightbox }" />
```

Or set it once for the app, as a file path:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nuxtPhoto: {
    lightbox: { component: '~/components/CaptionLightbox.vue' },
  },
})
```

In plain Vue, pass the component itself:
`app.use(createPhoto({ lightbox: { component: CaptionLightbox } }))`.

A `component` set on a gallery still wins. The app-wide component does not
turn a lightbox on: `Photo` and `PhotoCarousel` still need `lightbox`.

Your component renders inside the provider that the gallery creates. Do not
wrap it in another `LightboxProvider`, or it gets a second, empty state.

## Check the result

Open a photo and move through several: your caption and counter follow the
active photo. Press `Tab` through your buttons, then `Escape`: focus returns to
the thumbnail of the photo you were viewing.

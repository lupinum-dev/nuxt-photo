---
title: Public API
description: Supported imports for Nuxt apps, Vue apps, advanced customization, and internals.
---

Nuxt Photo has a small public API and a larger internal implementation. Use the
imports on this page for application code.

## Nuxt apps

Nuxt apps install `@nuxt-photo/nuxt`.

Most apps use auto-registered components and auto-imported composables. When
manual imports are clearer, import from the app facade:

```ts
import {
  PhotoAlbum,
  Lightbox,
  responsive,
  type PhotoItem,
  type LightboxCaptionSlotProps,
} from '@nuxt-photo/nuxt/app'
```

The app facade is the supported Nuxt import path for:

- recipe components
- lightbox primitives
- `useLightbox`, `useLightboxProvider`, and `useContainerWidth`
- `responsive` and `resolveResponsiveParameter`
- `PhotoItem`, `PhotoMapper`, image adapter types, layout types, and slot prop
  types
- extension keys such as `ImageAdapterKey`, `LightboxComponentKey`, and
  `LightboxDefaultsKey`

## Vue apps

Plain Vue apps install `@nuxt-photo/vue` and import from the root:

```ts
import {
  PhotoAlbum,
  Lightbox,
  responsive,
  type PhotoItem,
} from '@nuxt-photo/vue'
```

The root Vue entry exports the supported component, composable, primitive,
extension-key, and common type surface. It does not export internal layout,
image loading, geometry, viewer, or transition helpers.

## Advanced subpaths

These subpaths are public:

```ts
import { useLightbox } from '@nuxt-photo/vue/composables'
import { ImageAdapterKey } from '@nuxt-photo/vue/provide'
import type { LightboxCaptionSlotProps } from '@nuxt-photo/vue/types'
import '@nuxt-photo/vue/styles.css'
```

Use them when a package or bundler setup benefits from narrower imports. They
are not required for normal Nuxt app usage.

## Internal code

The source tree contains internal files under paths such as:

- `packages/vue/src/core`
- `packages/vue/src/internal`
- `packages/vue/src/context`
- `packages/vue/src/composables/ghost`
- `packages/vue/src/components/internal`

Do not deep-import those paths from application code. They are implementation
details and can change during a minor pre-1.0 release.

## Current root runtime exports

The Vue root runtime exports are intentionally limited to:

- `Photo`
- `PhotoGroup`
- `PhotoAlbum`
- `PhotoCarousel`
- `Lightbox`
- `LightboxProvider`
- `LightboxRoot`
- `LightboxOverlay`
- `LightboxViewport`
- `LightboxSlide`
- `LightboxControls`
- `LightboxCaption`
- `LightboxGhostImage`
- `PhotoImage`
- `PhotoTrigger`
- `useLightbox`
- `useLightboxProvider`
- `useContainerWidth`
- `responsive`
- `resolveResponsiveParameter`
- `photoId`
- `ImageAdapterKey`
- `LightboxComponentKey`
- `LightboxDefaultsKey`

Type exports include common photo, validation, layout, image adapter,
transition, responsive, controller, and slot prop types.

## Not public

These are examples of internals that are intentionally not exported from the
root:

- layout algorithms such as `computeRowsLayout`
- image loading helpers such as `loadImage`
- geometry and zoom helpers such as `computeZoomLevels`
- transition internals such as `chooseCloseTransition`
- recipe context keys such as `PhotoGroupContextKey`

If an internal helper seems useful for app code, open an issue or add a concrete
proposal before exporting it. A smaller public API is easier to support than a
broad accidental one.

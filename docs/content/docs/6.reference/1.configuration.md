---
title: Module configuration
description: Configure component registration, auto-imports, CSS, image delivery, and lightbox defaults.
---

Add Nuxt Photo to `modules`, then configure it under `nuxtPhoto`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    autoImports: true,
    components: { prefix: '' },
    css: 'structure',
    image: { provider: 'auto' },
  },
})
```

## Defaults

| Option        | Default                | Effect                                                                 |
| ------------- | ---------------------- | ---------------------------------------------------------------------- |
| `autoImports` | `true`                 | Imports `useLightbox`, `useLightboxProvider`, and `responsive`         |
| `components`  | `{ prefix: '' }`       | Registers the four recipe components without a prefix                  |
| `css`         | `'structure'`          | Loads layout and interaction CSS without the default theme             |
| `image`       | `{ provider: 'auto' }` | Uses Nuxt Image when its module is registered, otherwise native images |
| `lightbox`    | _none_                 | Leaves the built-in zoom default unchanged                             |

Unknown keys and invalid values fail during module setup with a namespaced error.

## Auto-imports

Set `autoImports` to `false` when the app uses explicit imports from `@nuxt-photo/nuxt/app`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    autoImports: false,
  },
})
```

A prefix changes all three generated names:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    autoImports: { prefix: 'Np' },
  },
})
```

This registers `useNpLightbox`, `useNpLightboxProvider`, and `npResponsive`.

## Components

The module registers `<Photo>`, `<PhotoAlbum>`, `<PhotoGroup>`, and `<PhotoCarousel>` by default. Disable registration or add a prefix when those names collide with app components.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    components: {
      prefix: 'Np',
      primitives: true,
    },
  },
})
```

`primitives: true` also registers the nine components used to compose a custom lightbox. The recipe `<Lightbox>` is not auto-registered; import it from `@nuxt-photo/nuxt/app` when you use it directly.

Set `components: false` to disable all component registration.

## CSS

| Value         | Loaded styles                                 |
| ------------- | --------------------------------------------- |
| `'structure'` | Album, photo, carousel, and lightbox geometry |
| `'all'`       | Structure plus the bundled visual theme       |
| `'none'`      | Nothing                                       |

Use `'all'` for a styled first gallery. Keep `'structure'` when the app supplies its own colors, typography, and controls. Choose `'none'` only when the app replaces every structural rule; columns, masonry, carousels, and lightboxes rely on those rules. The [CSS reference]($docs/reference/css) lists the supported variables and class hooks.

## Image provider

`image` accepts `false` or an object with a provider and optional thumbnail and slide settings.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt', '@nuxt/image'],
  nuxtPhoto: {
    image: {
      provider: 'nuxt-image',
      thumb: {
        sizes: 'sm:100vw md:50vw lg:400px',
        quality: 80,
      },
      slide: {
        widths: [640, 960, 1240, 1600, 2000],
        maxWidth: 1240,
        maxDensity: 1.5,
        sizes: 'min(1240px, calc(100vw - 72px))',
        quality: 85,
      },
    },
  },
})
```

| Provider       | Behavior                                                                             |
| -------------- | ------------------------------------------------------------------------------------ |
| `'auto'`       | Uses `@nuxt/image` when that module is registered; otherwise uses the native adapter |
| `'nuxt-image'` | Requires `@nuxt/image` in `modules` and fails after module setup when it is absent   |
| `'native'`     | Uses `src`, `thumbSrc`, and `srcset` without URL transformation                      |

`maxWidth` caps the main slide `src`. The generated `srcset` candidates are limited separately by `photo.width * maxDensity`, so a candidate can be wider than `maxWidth`.

`image: false` skips module-level adapter injection. `<PhotoImage>` still has its native fallback; provide `ImageAdapterKey` only when the app needs a custom global adapter. Thumbnail and slide settings apply only when Nuxt Image is the effective provider.

## Lightbox defaults

Set a positive, finite `minZoom` to change the lower bound for the maximum zoom
level in every provider.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    lightbox: {
      minZoom: 1.25,
    },
  },
})
```

The initial fitted scale remains `1`. A provider-level `minZoom` overrides the module default; without either value, the viewer uses `1.5`.

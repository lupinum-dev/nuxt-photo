title: CSS
description: Choose a CSS mode and customize stable recipe classes and theme variables.
---

The Nuxt module loads structure CSS by default. This preserves layout and interaction geometry while leaving visual styling to the application.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt-photo/nuxt'],
  nuxtPhoto: {
    css: 'structure',
  },
})
```

Use `css: 'all'` to add the bundled theme. Use `css: 'none'` only when the app replaces every structural rule.

Plain Vue applications load the complete structure and theme bundle from the public CSS entry:

```ts [src/main.ts]
import '@nuxt-photo/vue/styles.css'
```

## Theme variables

Override lightbox variables on `.np-lightbox`. The lightbox is teleported to `<body>`, so variables scoped only to an album ancestor do not reach it.

```css [app/assets/css/main.css]
.np-lightbox {
  --np-backdrop-bg: rgba(8, 10, 16, 0.92);
  --np-backdrop-filter: blur(16px);
  --np-btn-radius: 999px;
  --np-btn-bg: rgba(255, 255, 255, 0.1);
  --np-btn-hover-bg: rgba(255, 255, 255, 0.16);
  --np-btn-color: white;
  --np-btn-shadow: 0 16px 40px rgba(0, 0, 0, 0.24);
  --np-btn-blur: 8px;
  --np-btn-disabled-opacity: 0.45;
  --np-counter-color: rgba(255, 255, 255, 0.72);
  --np-img-radius: 14px;
  --np-img-shadow: 0 24px 80px rgba(0, 0, 0, 0.34);
  --np-caption-color: white;
  --np-caption-heading-size: 22px;
  --np-caption-secondary: rgba(255, 255, 255, 0.72);
}
```

Carousel variables live on `.np-carousel`:

```css [app/assets/css/main.css]
.np-carousel {
  --np-carousel-gap: 0.75rem;
  --np-carousel-slide-size: 100%;
  --np-carousel-slide-aspect: 16 / 10;
  --np-carousel-thumb-size: 5.5rem;
  --np-carousel-thumb-gap: 0.5rem;
  --np-carousel-radius: 0.5rem;
  --np-carousel-surface: rgba(0, 0, 0, 0.55);
  --np-carousel-surface-fg: #fff;
  --np-carousel-thumb-border: rgba(0, 0, 0, 0.1);
}
```

The `slideSize`, `slideAspect`, `gap`, and `thumbSize` props set their corresponding variables inline and therefore win on that carousel instance.

## Recipe classes

Use these roots to scope app styles:

| Recipe   | Root and common descendants                                                                                                                                    |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Album    | `.np-album`, `.np-album--rows`, `.np-album--columns`, `.np-album--masonry`, `.np-album__item`, `.np-album__img`                                                |
| Photo    | `.np-photo`, `.np-photo__img`, `.np-photo__caption`                                                                                                            |
| Carousel | `.np-carousel`, `.np-carousel__slide`, `.np-carousel__media`, `.np-carousel__controls`, `.np-carousel__caption`, `.np-carousel__thumb`, `.np-carousel__dot`    |
| Lightbox | `.np-lightbox`, `.np-lightbox__backdrop`, `.np-lightbox__controls`, `.np-lightbox__media`, `.np-lightbox__slide`, `.np-lightbox__caption`, `.np-lightbox__btn` |

Component class props extend the built-in classes without replacing them.

```vue [app/components/PortfolioGallery.vue]
<template>
  <PhotoAlbum :photos="photos" item-class="portfolio-frame" img-class="portfolio-image" />
</template>

<style scoped>
.portfolio-frame {
  border-radius: 0.5rem;
}

.portfolio-image {
  transition: transform 180ms ease;
}
</style>
```

When targeting library descendants from another scoped style block, use Vue's `:deep()` selector. Attributes beginning with `data-np-` coordinate gestures and transitions; treat them as implementation details rather than theme hooks.

This page collects every breaking or behavior-changing release note in one place. For unlisted patch releases, no action is needed.

## 0.3.0 (upcoming)

### PhotoCarousel opens a lightbox by default

`<PhotoCarousel>` previously rendered slides without a lightbox unless you set `:lightbox="true"`. The default is now `true`, matching `<PhotoAlbum>`, `<Photo>`, and `<PhotoGroup>`.

Action: if you relied on the old default, set `:lightbox="false"`.

```vue
<!-- Before -->
<PhotoCarousel :photos="photos" />

<!-- After, if you do not want a lightbox -->
<PhotoCarousel :photos="photos" :lightbox="false" />
```

### PhotoCarousel options are flat props

`loop`, `dragFree`, and `slidesToScroll` are now top-level props. The `options` bag still works but is deprecated; flat props win when both are set.

```vue
<!-- Before -->
<PhotoCarousel :photos="photos" :options="{ loop: true, slidesToScroll: 2 }" />

<!-- After -->
<PhotoCarousel :photos="photos" loop :slides-to-scroll="2" />
```

### transition is reactive

The `transition` prop on every recipe component is now reactive. Changing it at runtime takes effect at the next open/close. Code that remounted components purely to apply a new `transition` can drop that workaround.

The `lightbox` prop remains read once on mount; this is now documented explicitly.

### Programmatic controllers on every recipe

`<PhotoAlbum>` and `<Photo>` now expose `{ open, openById, close, isOpen }` through template refs, matching `<PhotoGroup>`. Code that wrapped albums in `PhotoGroup` only to open them programmatically can use the album ref directly.

### Localized labels

All built-in UI strings and accessibility labels are localizable through the new `nuxtPhoto.labels` module option or `usePhotoLabels()`. Nothing changes for English apps.

### Placeholder previews

`PhotoItem` accepts an optional `placeholder` field - a tiny LQIP or dominant-color data URI painted behind the image until it decodes. Existing photo data is unaffected; add the field when you want to remove load pop-in.

### Photo validation policy

`<Photo>` accepts `validation="drop"` to render nothing for invalid photos instead of throwing. The default `'throw'` behavior is unchanged.

### Stricter sizes validation

The structured `sizes` object on `<PhotoAlbum>` rejects values containing quotes, semicolons, or braces with a clear error instead of emitting broken CSS. A plain HTML `sizes` string is also accepted now and passes through verbatim.

### Silent fallbacks now warn

- `provider: 'auto'` without `@nuxt/image` logs one build-time warning.
- `image.thumb`/`image.slide` config without `@nuxt/image` logs one warning naming the dead keys.
- Set `nuxtPhoto.image.provider = 'native'` to declare native rendering and silence both.

### Typed app config

`useAppConfig().nuxtPhoto` is now checked against the declared `NuxtPhotoAppConfig` shape in every Nuxt project. Previously the augmentation shipped but was not wired into generated types; code that silently passed unknown keys may now fail typecheck. Remove unknown keys or extend the interface in your app.

## Earlier releases

### Custom lightbox primitives

`LightboxRoot` now owns the internal transition layer. Remove the old public transition primitive:

```vue [Before]
<LightboxRoot>
  <!-- custom lightbox -->
  <LightboxGhostImage class="my-transition-image" />
</LightboxRoot>
```

```vue [After]
<LightboxRoot>
  <!-- custom lightbox; the transition layer is rendered automatically -->
</LightboxRoot>
```

The viewport also owns media opacity. Remove the `mediaOpacity` slot binding and inline style:

```vue [Before]
<LightboxViewport v-slot="{ photos, viewportRef, mediaOpacity }">
  <div :ref="viewportRef" :style="{ opacity: mediaOpacity }">...</div>
</LightboxViewport>
```

```vue [After]
<LightboxViewport v-slot="{ photos, viewportRef }">
  <div :ref="viewportRef">...</div>
</LightboxViewport>
```

Backdrop blur is now a complete filter token and defaults to no filter:

```css [Before]
.np-lightbox {
  --np-backdrop-blur: 16px;
}
```

```css [After]
.np-lightbox {
  --np-backdrop-filter: blur(16px);
}
```

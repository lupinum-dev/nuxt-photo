---
title: Migrate from 0.2 to 1.0
description: Required API changes and new defaults for the 1.0 release candidate.
---

Nuxt Photo 1.0 is a clean cutover. It does not ship compatibility aliases for
the 0.2 API.

## 1. Rename the provider composable

```diff
- const lightbox = useLightboxProvider(photos)
+ const lightbox = provideLightbox(photos)
```

Keep `useLightbox()` for consuming the nearest provider.

## 2. Flatten carousel behavior

```diff
 <PhotoCarousel
   :photos="photos"
-  :options="{ loop: true, dragFree: false, slidesToScroll: 2 }"
+  loop
+  :drag-free="false"
+  :slides-to-scroll="2"
 />
```

`PhotoCarouselOptions` is no longer a public type. Embla remains internal.

## 3. Review lightbox defaults

All five recipes enable their lightbox by default. Add `:lightbox="false"` to
any `Photo`, `PhotoAlbum`, `PhotoGroup`, or `PhotoCarousel` that must remain
non-interactive.

Every recipe ref now shares `open`, `openById`, `close`, and readonly `isOpen`.
Carousel rail navigation uses `goToSlide`, `goToNextSlide`, and
`goToPreviousSlide`.

## 4. Split Nuxt configuration by owner

Keep only `components`, `autoImports`, `css`, and `image` under `nuxtPhoto` in
`nuxt.config.ts`.

Move UI defaults to `app.config.ts`:

```ts [app.config.ts]
export default defineAppConfig({
  nuxtPhoto: {
    lightbox: { minZoom: 1.2 },
    labels: {
      close: 'Close',
      counter: '{index} / {count}',
    },
  },
})
```

The Nuxt CSS default changed from `'structure'` to `'all'`. Set
`css: 'structure'` explicitly if your app already supplies the visual theme.

## 5. Keep image dimensions in your data pipeline

Every `PhotoItem` still requires accurate `width` and `height`. The removed
`measureImage()` helper is not replaced: store dimensions during upload or use
metadata returned by your CMS. `placeholder` accepts an image URL or data URI;
the library does not decode blurhash values.

## 6. Update advanced imports and labels

Use the documented root API or explicit component, primitive, composable,
provide, type, and stylesheet subpaths. Wildcard component paths and
undocumented deep imports are not supported.

Vue localization uses `providePhotoLabels()` and `usePhotoLabels()`. Indexed
Vue messages are functions; static Nuxt AppConfig messages use `{index}` and,
for counters, `{count}` placeholders.

## 7. Verify reactive data

Both `validation="throw"` and `validation="drop"` now re-evaluate when photo
data changes. Test invalid → valid → invalid updates if your CMS data arrives
incrementally. Removing a `lightbox` or `transition` override now restores the
default without a remount.

title: Use cases
description: Pick the smallest Nuxt Photo entry point for the gallery you are building.
---

Start with the highest-level component that owns the behavior you need. Move lower only when a concrete design requires it.

::decision-guide
::

## Photography portfolio

Use `<PhotoAlbum layout="rows">` for mixed landscape and portrait work. Justified rows preserve aspect ratios and make strong use of horizontal space.

## CMS-backed editorial gallery

Map CMS assets to `PhotoItem` at the data boundary, then pass the same collection to albums, groups, or carousels. Keep the CMS model out of view components.

[Build a CMS gallery](/docs/guides/build-a-cms-gallery)

## Several albums, one viewer

Wrap the albums in `<PhotoGroup :photos="allPhotos">`. The group collection owns next and previous order even when album sections move visually.

[Share a lightbox](/docs/guides/share-a-lightbox)

## Product image carousel

Use `<PhotoCarousel>` when horizontal browsing is the primary layout. Enable its lightbox only when a larger viewer adds value.

[Build a carousel](/docs/guides/build-a-carousel)

## Bespoke editorial layout

Use `<LightboxProvider>`, `<PhotoTrigger>`, and `<PhotoImage>` when thumbnails need custom markup but the default viewer remains correct.

[Create a custom thumbnail layout](/docs/guides/create-a-custom-thumbnail-layout)

## Fully branded viewer

Customize the recipe `<Lightbox>` with slots first. Use primitives only when the structure, focus order, or control placement must change.

[Customize the lightbox](/docs/guides/customize-the-lightbox)

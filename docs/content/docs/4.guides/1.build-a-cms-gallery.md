---
title: Build a CMS gallery
description: Map external assets to PhotoItem once, then render a responsive album.
---

The finished page keeps CMS-specific fields at the data boundary and gives Nuxt Photo one valid collection.

## Map the response

```vue
<script setup lang="ts">
import type { PhotoItem } from '@lupinum/nuxt-photo/app'

type Asset = {
  key: string
  url: string
  width: number
  height: number
  description?: string
}

const { data: assets } = await useFetch<Asset[]>('/api/photos')

const photos = computed<PhotoItem[]>(() =>
  (assets.value ?? []).map((asset) => ({
    id: asset.key,
    src: asset.url,
    width: asset.width,
    height: asset.height,
    alt: asset.description,
  })),
)
</script>

<template>
  <PhotoAlbum :photos="photos" layout="rows" />
</template>
```

## Keep the boundary strict

- Use the CMS asset ID, not the array index.
- Preserve intrinsic pixel dimensions.
- Map optional text to `alt`, `caption`, and `description` deliberately.
- Precompute signed URLs before rendering so server and client receive the same value.

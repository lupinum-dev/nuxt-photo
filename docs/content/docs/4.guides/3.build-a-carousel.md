---
title: Build a carousel
description: Add horizontal browsing, thumbnails, autoplay, and an optional lightbox.
---

`PhotoCarousel` owns Embla integration behind three flat behavior props.

```vue
<template>
  <PhotoCarousel
    :photos="photos"
    loop
    :slides-to-scroll="1"
    show-thumbnails
    show-counter
    slide-aspect="16/9"
  />
</template>
```

::carousel-lab
::

## Add autoplay deliberately

```vue
<PhotoCarousel
  :photos="photos"
  :autoplay="{
    delayMs: 4500,
    stopOnInteraction: true,
    stopOnMouseEnter: true,
  }"
/>
```

Autoplay should stop when it competes with reading, pointer interaction, or reduced-motion preferences.

## Failure modes

- `lightbox` is on by default for carousels; set it to `false` for an inert rail.
- Actual snap groups depend on rendered geometry.
- Embla plugin objects are not part of the public API.

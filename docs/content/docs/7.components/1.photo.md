---
title: Photo
description: Render one photo as an inert figure, a grouped trigger, or a solo lightbox.
---

`<Photo>` renders a `<figure>`, one adapter-backed image, and an optional caption.

```vue [app/components/HeroPhoto.vue]
<script setup lang="ts">
import type { PhotoItem } from '@nuxt-photo/nuxt/app'

const photo: PhotoItem = {
  id: 'desert-dawn',
  src: '/photos/desert-dawn.jpg',
  width: 1600,
  height: 1000,
  alt: 'Low morning light crossing a desert ridge',
  caption: 'Desert dawn',
}
</script>

<template>
  <Photo :photo="photo" lightbox />
</template>
```

## Props

| Prop             | Type                       | Default               | Purpose                                              |
| ---------------- | -------------------------- | --------------------- | ---------------------------------------------------- |
| `photo`          | `PhotoItem`                | required              | Image data and stable identity                       |
| `lightbox`       | `boolean \| Component`     | disabled              | Enables a solo lightbox or supplies its UI component |
| `lightboxIgnore` | `boolean`                  | `false`               | Makes this trigger inert inside a `PhotoGroup`       |
| `imageAdapter`   | `ImageAdapter`             | injected, then native | Overrides image delivery for this photo              |
| `transition`     | `LightboxTransitionOption` | `'auto'`              | Configures a standalone lightbox transition          |
| `loading`        | `'lazy' \| 'eager'`        | `'lazy'`              | Sets the thumbnail's native loading mode             |
| `imgClass`       | `string`                   | none                  | Adds classes to the inner image                      |
| `captionClass`   | `string`                   | none                  | Adds classes to the figcaption                       |

Normal attributes such as `class`, `id`, and data attributes are forwarded to the `<figure>`.

## Modes

Without a group or `lightbox`, the figure is inert. Set `lightbox` to `true` to create a one-photo viewer, or pass a component to replace the viewer UI.

Inside `<PhotoGroup>`, the group owns the provider and navigation order. The photo becomes a trigger only when its ID exists in the group's canonical collection. Its own `lightbox` prop is ignored; `lightboxIgnore` opts out this particular thumbnail without removing the photo from programmatic navigation.

`lightbox`, `transition`, and the provider-facing adapter are setup-time options. Remount with a new `key` when they change.

## Custom slide

The `slide` slot replaces lightbox media for this photo and receives `{ photo, index }`.

```vue [app/components/VideoPoster.vue]
<template>
  <Photo :photo="poster" lightbox>
    <template #slide="{ photo }">
      <video :src="String(photo.meta?.videoSrc)" controls />
    </template>
  </Photo>
</template>
```

Interactive photos support click, Enter, and Space. The trigger label uses `alt` when present; provide meaningful alternative text instead of relying on a generated ordinal.

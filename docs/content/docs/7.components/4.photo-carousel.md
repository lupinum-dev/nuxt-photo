---
title: PhotoCarousel
description: Render a swipeable photo rail with optional controls, thumbnails, autoplay, and lightbox.
---

`<PhotoCarousel>` owns a small, library-defined carousel API. Embla drives geometry internally without exposing arbitrary vendor options or plugins.

```vue [app/components/StoryCarousel.vue]
<template>
  <PhotoCarousel
    :photos="photos"
    :options="{ loop: true, slidesToScroll: 1 }"
    :autoplay="{ delayMs: 4500, stopOnInteraction: true, stopOnMouseEnter: true }"
    :lightbox="true"
  />
</template>
```

## Props

| Prop                                                                    | Type                                      | Default                                       |
| ----------------------------------------------------------------------- | ----------------------------------------- | --------------------------------------------- |
| `photos`                                                                | `readonly PhotoItem[]`                    | required                                      |
| `validation`                                                            | `'throw' \| 'drop'`                       | `'throw'`                                     |
| `invalidPhotos` event                                                   | `(event: InvalidPhotosEvent) => void`     | none                                          |
| `imageAdapter`                                                          | `ImageAdapter`                            | injected, then native                         |
| `options`                                                               | `PhotoCarouselOptions`                    | loop off, drag-free off, one slide per scroll |
| `showArrows`                                                            | `boolean`                                 | `true`                                        |
| `showThumbnails`                                                        | `boolean`                                 | `true`                                        |
| `showCounter`                                                           | `boolean`                                 | `true`                                        |
| `showDots`                                                              | `boolean`                                 | `false`                                       |
| `autoplay`                                                              | `boolean \| PhotoCarouselAutoplayOptions` | `false`                                       |
| `slideSize`                                                             | `string`                                  | CSS default `100%`                            |
| `slideAspect`                                                           | `string`                                  | CSS default `16 / 10`                         |
| `gap`                                                                   | `string`                                  | CSS default `0.75rem`                         |
| `thumbSize`                                                             | `string`                                  | CSS default `5.5rem`                          |
| `lightbox`                                                              | `boolean \| Component`                    | `false`                                       |
| `transition`                                                            | `LightboxTransitionOption`                | `'auto'`                                      |
| `slideClass`, `imgClass`, `thumbClass`, `captionClass`, `controlsClass` | `string`                                  | none                                          |

Normal attributes are forwarded to the carousel root. An empty collection renders an empty root; one photo suppresses arrows, counter, thumbnails, and dots.

## Options

```ts [app/utils/carousel-options.ts]
const options: PhotoCarouselOptions = {
  loop: false,
  dragFree: false,
  slidesToScroll: 1,
}
```

`slidesToScroll` must be a positive integer. Autoplay accepts a positive finite `delayMs`; `stopOnInteraction` defaults to `true`, and `stopOnMouseEnter` defaults to `false`.

Autoplay does not inspect `prefers-reduced-motion`. Gate the prop in application code when motion preferences should disable automatic movement.

## Slots

| Slot       | Props                                                                              |
| ---------- | ---------------------------------------------------------------------------------- |
| `slide`    | `{ photo, index, selected, open }`                                                 |
| `thumb`    | `{ photo, index, selected, goTo }`                                                 |
| `caption`  | `{ photo, index, count }`                                                          |
| `controls` | `{ goToPrev, goToNext, canGoToPrev, canGoToNext, selectedIndex, snapCount, goTo }` |
| `prev`     | none                                                                               |
| `next`     | none                                                                               |
| `dots`     | `{ snaps, selectedIndex, goTo }`                                                   |

The `slide` and `thumb` slots replace their default `<PhotoImage>`. Render `<PhotoImage>` yourself to preserve adapter-backed image delivery.

With several visible slides, control and caption `selectedIndex` means the first active slide. The dots slot receives the selected snap index, while `snaps` contains the first slide index targeted by each real geometry-derived snap.

Main frames use image context `slide`; the thumbnail rail uses `thumb`. The first main image loads eagerly and later images lazily.

`lightbox`, `transition`, and its provider adapter are setup-time options. Remount when they change. The default carousel and lightbox strings are English; replace controls and dots when the product needs localized labels.

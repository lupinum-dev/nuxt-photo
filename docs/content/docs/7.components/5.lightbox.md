---
title: Lightbox
description: Customize the built-in viewer through focused counter, action, caption, and slide slots.
---

`<Lightbox>` is the viewer recipe used by the higher-level components. It has no props and requires an existing lightbox provider. The Nuxt module does not auto-register it, so import it explicitly.

```vue [app/components/BrandedLightbox.vue]
<script setup lang="ts">
import { Lightbox } from '@nuxt-photo/nuxt/app'
</script>

<template>
  <Lightbox>
    <template #counter="{ activeIndex, count }">
      <span>{{ activeIndex + 1 }} of {{ count }}</span>
    </template>

    <template #caption="{ photo }">
      <div>
        <strong>{{ photo?.caption }}</strong>
        <p>{{ photo?.description }}</p>
      </div>
    </template>
  </Lightbox>
</template>
```

Pass the wrapper to an enabled recipe:

```vue [app/pages/gallery.vue]
<script setup lang="ts">
import BrandedLightbox from '~/components/BrandedLightbox.vue'
</script>

<template>
  <PhotoAlbum :photos="photos" :lightbox="BrandedLightbox" />
</template>
```

Do not call `useLightboxProvider()` inside this wrapper. The album, group, photo, or carousel already owns the provider.

## Slots

| Slot      | Props                                                                                              |
| --------- | -------------------------------------------------------------------------------------------------- |
| `counter` | `{ activeIndex, count }`                                                                           |
| `actions` | `{ activeIndex, count, prev, next, close, toggleZoom, isZoomedIn, zoomAllowed, controlsDisabled }` |
| `caption` | `{ photo, index }`                                                                                 |
| `slide`   | `{ photo, index, width, height }`                                                                  |

The default viewer loops through its collection, so custom actions should not disable previous and next solely because the active item is first or last. Disable controls while `controlsDisabled` is true and disable zoom when `zoomAllowed` is false.

The built-in recipe supplies dialog semantics, focus isolation, a live announcement, image failure feedback, and English labels. Replace the relevant slots when visible controls need product-specific language. A completely different DOM structure belongs on the [lightbox primitives]($docs/components/lightbox-primitives) layer.

Providing `LightboxComponentKey` at app level replaces the viewer for recipes whose lightbox is already enabled. It does not turn on the opt-in lightbox defaults of `<Photo>` or `<PhotoCarousel>`.

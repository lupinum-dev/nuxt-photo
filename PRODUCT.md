# Nuxt Photo product context

## Product

Nuxt Photo is a Nuxt 4 and Vue component system for photo albums, galleries, carousels, and shared lightboxes built from real image metadata.

## Users and purpose

It serves Nuxt and Vue teams that know each image's source and dimensions and want predictable SSR layouts, accessible interaction, shared lightbox behavior, and optional Nuxt Image integration without assembling several unrelated libraries.

The documentation should help a developer decide whether the model fits, reach a correct first gallery quickly, understand ownership and responsive behavior, and confidently customize the lower-level primitives.

## Personality

Visual, calm, precise, and gallery-like. The interface should put examples and photography first, use warm amber as a restrained accent, and avoid decorative effects that compete with the images.

## Accessibility

Target WCAG 2.2 AA. Keyboard access, visible focus, reduced motion, readable contrast, stable layout, and understandable lightbox controls are core product requirements rather than optional polish.

## Design principles

- Photography is the visual proof; the shell stays quiet.
- Demonstrate real dimensions and behavior instead of promising them abstractly.
- Keep developer guidance direct and technically exact.
- Preserve a clear path from a first album to fully custom rendering.

# Product

Nuxt Photo is a Nuxt-first library for responsive galleries, shared lightboxes,
and carousels built from one explicit photo model.

## Users

Nuxt and Vue developers who need photo galleries, lightboxes, and carousels
without giving up server-rendered layout, image delivery, accessibility, or
control over markup.

## Documentation purpose

Nuxt Photo turns one explicit photo model into responsive albums, shared
lightboxes, and carousels. Its documentation should get a developer to a
working gallery quickly, teach the few mental models that prevent mistakes,
and provide exact reference material when they need to configure or extend the
library.

## Brand Personality

Precise, calm, tactile, and trustworthy. The voice is direct and practical,
like the best Nuxt documentation: explain the decision, show a small working
example, and stop when the reader can continue on their own.

## Anti-references

- Generic AI documentation with repeated summaries, link dumps, and identical
  "what's next" endings.
- API reference before the reader has seen a working result.
- Sidebar mazes with unnecessary nesting or contributor internals mixed into
  user documentation.
- Decorative gradients, glass effects, card grids, or stock illustrations
  that compete with the photography.
- Interactive controls that do not map to real public options or do not change
  the rendered behavior they claim to control.

## Design Principles

- Show the result before explaining the machinery.
- Keep every example source-accurate and copyable.
- Let photography carry the visual proof; keep the documentation chrome quiet.
- Use interactive controls only when changing a setting teaches something.
- Move from recipes to concepts to reference through progressive disclosure.
- Keep one canonical explanation and one canonical playground for each topic.

## Accessibility

Target WCAG 2.2 AA. Every playground must work with a keyboard, expose native
labels and state, preserve visible focus, respect reduced motion, maintain
sufficient contrast, and avoid layout shifts. Photos need meaningful alt text
or an intentional empty alt attribute. Modal examples must restore focus after
closing.
